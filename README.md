# منصة الصحة النفسية وذوي الاحتياجات الخاصة

منصة عربية منظمة في علم النفس والصحة النفسية والتربية الدامجة والدعم العملي، انطلقت باسم **مصطلحات علم النفس | Psychology Terminology** وترتبط بالمحتوى المرئي المنشور عبر **@pterminology**.

- الموسوعة الموسعة: https://khaledaltheeb.github.io/pterminology-site/encyclopedia/
- المعجم الأساسي: https://khaledaltheeb.github.io/pterminology-site/terms/
- المراكز الموضوعية: https://khaledaltheeb.github.io/pterminology-site/hubs/
- واجهة المطورين: https://khaledaltheeb.github.io/pterminology-site/developers/

- Instagram: https://www.instagram.com/pterminology/
- YouTube: https://www.youtube.com/@psychology-term
- Sitemap Index: https://khaledaltheeb.github.io/pterminology-site/sitemap.xml

## البنية الحالية

- 2000 صفحة مفهوم وموضوع نفسي مستقلة.
- 200 صفحة مركزية تربط المحتوى في مجموعات موضوعية.
- أكثر من 2000 عنوان قابل للفهرسة عبر Sitemap Index مجزأ.
- واجهة بحث عربية/إنجليزية.
- صفحات مستقلة بعناوين ووصف وCanonical وhreflang وJSON-LD.
- ملفات API وCSV قابلة للتنزيل.
- نظام استيراد للمحتوى المنظم دون تعديل القوالب.
- اختبارات تمنع التكرار ونقص الصفحات وفساد خرائط الموقع.
- ملف تحقق Google Search Console محفوظ في جذر الموقع.

## API العامة والتكاملات

ينشر خط الإنتاج واجهة قراءة ثابتة تحت `api/v1/` تشمل حالة الواجهة، وبيانات المنصة، وفهرس الأقسام، والدورات المصرح باستيراد فهارسها، ومرجع OpenAPI 3.1.

استيراد الدورات يعمل بسياسة **رفض افتراضي**. لا يُفعّل أي مصدر قبل وجود:

- إذن مكتوب ومرجع داخلي قابل للتدقيق.
- تاريخ منح الإذن ورابط الترخيص.
- تصريح صريح باستيراد الفهرس.
- نطاقات HTTPS مدرجة في قائمة السماح.
- صيغة JSON أو CSV وحدود للحجم وعدد السجلات والتحويلات.

وجود دورة في API لا يعني اعتمادها علميًا ولا يمنح حق نسخ موادها؛ تبقى شروط الجهة المالكة هي المرجع.

## خرائط الموقع

- `sitemap.xml`: الفهرس الرئيسي.
- `sitemap-terms-1.xml`: أول 1000 صفحة.
- `sitemap-terms-2.xml`: ثاني 1000 صفحة.
- `sitemap-hubs.xml`: المراكز الموضوعية.
- `sitemap-core.xml`: الصفحات الأساسية والأدلة والأدوات.
- `sitemap-developers.xml`: توثيق API والمطورين.

## توسيع المحتوى

استخدم الملف:

```text
content/import-template.csv
```

وتفاصيل الحقول والقواعد موجودة في:

```text
content/README.md
```

تعتمد بنية SEO أساسًا على نية البحث، والعنوان والوصف، والعناوين الداخلية، والروابط الموضوعية، والبيانات المنظمة. يُسمح في الصفحات الأساسية بوسم `meta keywords` مختصر للتوافق والتنظيم بحد أقصى 15 عبارة، ولا يُعامل بوصفه أساس الترتيب. توجد خريطة موضوعية في `content/seo/keyword-taxonomy-v215.json` لتوحيد المصطلحات والمرادفات ونوايا البحث ومنع الحشو.

## منهج المحتوى

المحتوى للتثقيف العام، ويُبنى على الوضوح، والربط الداخلي، والتمييز بين المفاهيم، والمصادر القابلة للتحقق، وتجنب التشخيص السريع والوصم والادعاءات المطلقة.

## سياسة النشر

يُبنى الموقع ويُنشر من أحدث `main` فقط بعد نجاح بوابات الإنتاج، مع ختم `deployment.json` ومطابقة SHA والملفات الحرجة على النسخة الحية. لا تُعرض نصوص التنفيذ أو خطط العمل أو حالات الفروع داخل صفحات المستخدم.
