# عقد تفسير التقرير المهني v2

تضيف هذه الطبقة حقولًا إلزامية تميز بين المسح، والتقييم التشخيصي، والتقييم الوظيفي، ومتابعة التقدم.

## قواعد التشغيل

- لا تتحول نتيجة المسح أو الدرجة المنفردة إلى تشخيص آلي.
- يجب توثيق صلاحية النتيجة وحدودها قبل حفظ التقرير.
- تقرير متابعة التقدم يتطلب خط أساس وهدفًا قابلًا للقياس وطريقة قياس وموعد إعادة قياس.
- فتح تقرير محفوظ ثم حفظه ينتج إصدارًا جديدًا مرتبطًا بالإصدار السابق، ولا يطمس السجل الأصلي.
- يجب تسجيل سبب الإصدار الجديد والحقول التي تغيرت.
- الملخص الأسري منفصل عن الصياغة المهنية، ويشرح النتيجة وحدودها والخطوة التالية بلغة واضحة.
- لا تتضمن الطبقة بنود اختبارات تجارية أو مفاتيح تصحيح أو معايير أو مقتطفات من الأدلة المحمية.
