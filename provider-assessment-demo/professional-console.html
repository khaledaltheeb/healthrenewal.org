بوابة موحدة للسجل التشغيلي

اختر المقياس أو الفحص، اربطه بالحالة، ووثّق التطبيق والنتيجة والخطوة التالية.

لا تستخدم هذه الصفحة نظامًا منفصلًا أو حسابًا تجريبيًا. تنقلك مباشرة إلى السجل المهني داخل منصة التقييم الرئيسية، حيث تبقى الحالات والجلسات والتطبيقات المهنية في مساحة UID المحلية نفسها.

فتح المقاييس والفحوص المهنية فتح التطبيقات المسجلة اختيار مسار حالة

ما الذي يحفظه السجل؟

  • الحالة ورقمها المستعار.
  • اسم المقياس أو الفحص والمجال.
  • المنفذ والاختصاص والجهة.
  • التاريخ وطريقة التطبيق.
  • الإصدار واللغة والتكييفات.
  • صلاحية التطبيق والقيود.
  • النتيجة والدرجة أو مرجع التقرير.
  • الملاحظات والخطوة التالية.

سجل واحد للحالة

تظهر الجلسات الاستكشافية والتطبيقات المهنية المتكررة في المساحة المحلية نفسها، دون إنشاء قاعدة بيانات ثانية أو حساب موازٍ.

كل العناصر قابلة للتشغيل

كل مقياس يفتح مسارًا للتخطيط والتعيين والتوثيق، وكل فحص جهازي يفتح مسارًا لاستيراد خلاصة الجهة المختصة.

قوالب بحسب نوع الأداة

تتغير حقول الإدخال تلقائيًا وفق طبيعة الاستبانة أو اختبار الأداء أو المقابلة أو الفحص أو التصنيف أو التواصل أو تحليل السلوك.

عائلات القوالب المهنية

الاستبانة ومقياس التقدير

المجيب والدرجة الخام والمعيارية والمئين والمجالات واتساق المصادر.

اختبار الأداء والقدرات

الاكتمال والمشاركة والمؤشرات وفاصل الثقة والملاحظة أثناء الجلسة.

المقابلة والملاحظة المنظمة

الوحدة والمدة والسياقات والتاريخ والملاحظات المباشرة.

الفحص الخارجي أو الجهازي

الجهة والجهاز والقياس والوحدة ومرجع التقرير وتصنيف النتيجة.

التصنيف الوظيفي والحركي

المستوى والمساعدة والأجهزة واختلاف الأداء ومقياس التغير المكمل.

التحليل الوظيفي للسلوك

التعريف والتكرار والمدة والشدة والسوابق والنتائج والفرضية والسلامة.

اللغة والتواصل المعزز

وسائل التواصل والوظائف وطريقة الوصول والتجربة ودعم الشركاء.

مسار العمل المختصر

أنشئ الحالة

استخدم اسمًا مستعارًا وحدد العمر واللغة والمصدر وسؤال الإحالة.

اختر المسار

ابدأ من حالة أو مجال ثم اختر المقياس والفريق المناسبين.

وثق التطبيق

أدخل المنفذ والطريقة والنسخة والمصادر والتكييفات والنتائج.

راجع الصلاحية

حدد إن كانت النتيجة صالحة أو تحتاج تحفظًا أو إعادة تطبيق.

اختر القرار التالي

أداة مكملة أو جمع معلومات أو مراجعة فريق أو خطة دعم أو إغلاق.

راجع السجل زمنيًا

قارن التطبيقات المتكررة واربطها بمؤشرات المتابعة.

التخزين في الاستضافة الحالية محلي داخل الجهاز والمتصفح. لا تُدخل أسماء كاملة أو أرقام هوية أو ملفات طبية حساسة. التطبيق الرسمي للمقياس يتم باستخدام مواده الأصلية المصرح بها وبواسطة شخص مؤهل.
