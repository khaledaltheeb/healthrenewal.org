# دليل الأسرة v342

مرجع أسري مستقل ومترابط مع مركز الأشخاص ذوي الاحتياجات الخاصة ومسارات التقييم المهني، من فهم الحالة إلى الخطة والمتابعة والأمان والاستقلال.

## الحالة المنشورة

- **64 دليل حالة** ضمن قالب موحد: 56 حالة في المصدر الأساسي و8 حالات في امتداد المرحلة الثامنة.
- صفحة مركزية قابلة للبحث بالعربية والإنجليزية واسم الجين.
- ثلاث أدوات قابلة للطباعة: خطة الأسرة، سجل السلوك والسياق، وتحضير موعد التقييم.
- واجهة API مجمعة `api/family-guide-v2.json` تحفظ توافق المصدر الأساسي وتعلن الامتداد الجديد.
- خريطتا موقع للدليل، وكلتاهما مسجلتان في فهرس خرائط الموقع.
- اختبارات تحقق بنيوية وتحريرية وإتاحة وغلاف مؤسسي وسلامة مصادر.

## الحالات المضافة في المرحلة الثامنة

CDKL5، FOXG1، متلازمة درافيت/SCN1A، الازدواج الأمومي 15q، ازدواج MECP2، حذف 1p36، اضطرابات KCNQ2، والاضطراب المرتبط بـGRIN2B.

## القالب الإلزامي لكل حالة

التعريف والتصنيف، العلامات، الأسباب وحدود المعرفة، الأقسام المرتبطة، الخطوات الأولى، ما يجب تجنبه، التعامل اليومي، خطط 30 و90 يومًا وسنة، علامات الاستعجال، الفريق، الأسئلة، والمراجع.

## منهج المراجعة

- آخر مراجعة: 2026-07-30.
- تعتمد المراجع الأساسية على المصادر الحكومية والإرشادات المهنية وGeneReviews وNCBI/NIH والمراجع الأكاديمية الأولية بحسب الحالة.
- لا تشخيص آلي، لا جرعات، لا استبدال للتقييم الفردي، ولا نسخ لمقاييس محمية.
- تراجع الحالات عند تغير الإرشادات أو ظهور بيانات تؤثر في السلامة أو الخطة العملية.
- لا تعد كلمة «مكتمل» وعدًا بنهاية التطوير؛ بل تعني أن كل صفحة اجتازت العقد التحريري الحالي، مع بقاء التحديث العلمي مستمرًا.
