# دليل الأسرة v340

مرجع أسري مستقل ومترابط مع مركز ذوي الاحتياجات الخاصة ومسارات التقييم المهني، من فهم الحالة إلى الخطة والمتابعة والأمان والاستقلال.

## المحتويات

- صفحة مركزية قابلة للبحث بالعربية والإنجليزية.
- 24 دليل حالة مكتملًا ضمن قالب موحد.
- ثلاث أدوات قابلة للطباعة: خطة الأسرة، سجل السلوك والسياق، وتحضير موعد التقييم.
- API JSON عام للفهرسة والتكامل.
- Sitemap مستقل مسجل ضمن فهرس خرائط الموقع.
- اختبارات تحقق بنيوية وتحريرية وإتاحة وغلاف مؤسسي.

## القالب الإلزامي لكل حالة

التعريف والتصنيف، العلامات، الأسباب وحدود المعرفة، الأقسام المرتبطة، الخطوات الأولى، ما يجب تجنبه، التعامل اليومي، خطط 30 و90 يومًا وسنة، علامات الاستعجال، الفريق، الأسئلة، والمراجع.

## منهج المراجعة

- آخر مراجعة: 2026-07-30.
- تعتمد المراجع الأساسية على المصادر الحكومية والإرشادات المهنية والمراجع الجينية والأكاديمية الأولية بحسب الحالة.
- لا تشخيص آلي، لا جرعات، لا استبدال للتقييم الفردي، ولا نسخ لمقاييس محمية.
- تراجع الحالات عند تغير الإرشادات أو ظهور بيانات تؤثر في السلامة أو الخطة العملية.
