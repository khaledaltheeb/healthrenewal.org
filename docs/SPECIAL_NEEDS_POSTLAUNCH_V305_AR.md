# تدقيق ما بعد إطلاق بوابتي التوحد ومتلازمة داون v305

## النطاق

تضيف هذه الطبقة تحسينات تقنية وتنظيمية بعد توليد الصفحتين العلميتين، دون تغيير الادعاءات السريرية أو المراجع الأصلية داخل محتوى v302.

## التحسينات

- مسار تنقل مرئي ومتوافق مع قارئات الشاشة.
- روابط سياقية إلى الأدلة العملية الموجودة فعليًا في الموقع.
- إرشادات مختصرة لاستخدام الدليل دون تشخيص ذاتي.
- سياسة شفافة لإدراج الأطباء والمراكز ومقدمي الخدمات.
- تحسينات Open Graph وTwitter وبيانات تاريخ التعديل وسياسة الإحالة.
- نمط تركيز واضح للوحة المفاتيح ودعم أفضل للطباعة والشاشات الصغيرة.
- فحص تلقائي لمنع الروابط الداخلية المكسورة والمعرّفات المكررة وفتح النوافذ غير الضروري.

## العقود

- المحتوى العلمي الأساسي: v302.
- تكامل أدلة ذوي الاحتياجات الخاصة: v221.
- طبقة التدقيق والربط اللاحقة: v305.

## المخرجات الآلية

ينتج الناشر التقرير:

`api/special-needs-condition-postlaunch-v305.json`

ويتضمن عدد الروابط، حالة الميتا، مسار التنقل، سياسة مقدمي الخدمات، الحد الأدنى للكلمات والعناوين، ونتيجة الفحص لكل صفحة.
