# التدقيق الحي لاكتشاف محركات البحث v1

## الهدف

إضافة طبقة تحقق مستقلة تقارن ما تنشره المنصة فعليًا مع ما تستطيع محركات البحث الوصول إليه، دون تعديل أي صفحة أو ملف SEO أو إعداد استضافة.

## قاعدة السلامة

هذا المسار للقراءة فقط. لا يقوم بأي من الآتي:

- حذف أو اختصار أو استبدال محتوى.
- تعديل `robots.txt` أو ملفات Sitemap.
- تغيير Canonical أو Hreflang أو البيانات المنظمة.
- تعديل DNS أو إعدادات GitHub Pages أو Hostinger.
- إرسال أو حذف عناوين من Google Search Console أو Bing Webmaster Tools.
- إرسال IndexNow.
- عمل Commit تلقائي أو نشر نسخة جديدة من الموقع.

## ما يفحصه

1. وصول `robots.txt` وحالة HTTP.
2. جميع تعليمات `Sitemap:` المعلنة في `robots.txt`.
3. ملفات Sitemap المتداخلة حتى عمق آمن ومحدد.
4. الروابط المكررة عبر خرائط الموقع.
5. حالة HTTP لكل عنوان مدرج في Sitemap.
6. نوع المحتوى وإدراج عناوين غير HTML داخل Sitemap.
7. وجود `noindex` على عنوان مدرج في Sitemap.
8. وجود Canonical وتطابقه مع عنوان Sitemap.
9. التحويل خارج النطاق القانوني `healthrenewal.org`.
10. إشارات Hreflang المنشورة داخل رأس الصفحة لتضمينها في التقرير.

## المخرجات

ينشئ التشغيل ملفين داخل Artifact خاص بكل تشغيل:

- `reports/live-search-discovery-v1.json`: تقرير كامل قابل للقراءة آليًا.
- `reports/live-search-discovery-v1.md`: ملخص واضح داخل GitHub Actions.

تُحفظ Artifacts لمدة 30 يومًا، ولا تُضاف التقارير المتغيرة إلى فرع `main`.

## التشغيل

يعمل المسار:

- يدويًا من GitHub Actions.
- يوميًا الساعة `02:37 UTC`.
- عند تعديل الأداة أو اختباراتها أو Workflow أو هذا المستند داخل Pull Request.

الحد الافتراضي للفحص هو 5000 عنوان، ويمكن تغييره في التشغيل اليدوي.

## تفسير الحالة

### فشل حرج

يُعد التشغيل فاشلًا عند وجود مشكلة تمنع الاكتشاف أو الفهرسة المتوقعة، مثل:

- تعذر الوصول إلى `robots.txt`.
- عدم إعلان أي Sitemap.
- تعذر تحميل Sitemap أو فساد XML.
- رابط Sitemap يعيد خطأ HTTP.
- صفحة مدرجة في Sitemap تحمل `noindex`.
- تحويل رابط مدرج إلى نطاق آخر.

### تحذير

لا يمنع التشغيل افتراضيًا، لكنه يظهر بوضوح، مثل:

- Canonical مفقود أو غير مطابق.
- عنوان غير HTML داخل Sitemap.
- تكرار عنوان عبر أكثر من Sitemap.
- تجاوز حد عدد الروابط المحدد للتشغيل.

## الاختبارات

تغطي الاختبارات المحلية:

- تطبيع الروابط.
- قراءة تعليمات Sitemap من `robots.txt` وإزالة التكرار.
- قراءة `urlset` و`sitemapindex`.
- استخراج Canonical وRobots وHreflang والعنوان من HTML.
- رفض اختلاف النطاق بين `healthrenewal.org` و`www.healthrenewal.org` باعتبارهما أصلين مختلفين حتى يكون التحويل القانوني واضحًا.
