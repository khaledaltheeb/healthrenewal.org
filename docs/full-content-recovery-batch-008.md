## قرار الاستعادة

لا تُستعاد نسخة PR #548 الآن كصفحة ثانية مستقلة لمجرد أن مسارها التاريخي مفقود. السبب أن موضوعها وجمهورها ومجموعة أقسامها أصبحت ممثلة بدرجة كبيرة داخل الصفحة الحالية في `provider-assessment-demo/conditions/global-developmental-delay/`. إعادة الصفحة التاريخية كاملة كما هي ستنشئ صفحتين متداخلتين جدًا في نية البحث والمحتوى، مع Canonical تاريخي قديم على نطاق GitHub Pages السابق.

في الوقت نفسه لا يُعتبر المحتوى التاريخي مستغنى عنه أو محذوفًا. Git blob التاريخي محفوظ ويجب التعامل معه كمصدر مقارنة. أي فقرة أو نصيحة أو معلومة علمية فريدة لا تظهر في النسخة الحالية تُدمج داخل الصفحة الحالية الأقوى، بدل إعادة إنشاء مسار موازٍ.
