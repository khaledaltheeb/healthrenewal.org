# سياسة حقوق المصادر وإعادة الاستخدام

**المالك:** Psychology Terminology  
**الإصدار:** 1.0.0  
**تاريخ النفاذ:** 2026-07-31  
**السجل الآلي:** `api/source-rights-registry.json`

## 1. الغرض

تحدد هذه السياسة الطريقة التي تكتشف بها المنصة المصادر الخارجية، وتربط إليها، وتقتبس منها، وتترجمها، وتكيفها، وتعيد توزيعها. الهدف هو منع أربعة أخطاء مؤسسية:

1. اعتبار المجانية ترخيصًا مفتوحًا.
2. الخلط بين المصدر والشريك أو الجهة المعتمدة.
3. نشر ترجمة أو مادة مشتقة دون سند حقوقي قابل للتتبع.
4. فقدان بيانات الإسناد والإصدار والتغييرات بعد النشر.

## 2. نطاق التطبيق

تنطبق السياسة على:

- الكتب والفصول والمواد التعليمية.
- الدورات والندوات والتسجيلات والشهادات.
- الإرشادات والتقارير ومخرجات مجموعات العمل.
- الصور والشعارات والفيديوهات والرسوم والجداول.
- البيانات الوصفية وواجهات API والتغذيات الآلية.
- الترجمة والتلخيص والتكييف وإعادة النشر والاستضافة.

لا تنطبق على الحقائق العامة المجردة، لكنها تظل خاضعة لمعايير الدقة والاستشهاد بالمصدر الأنسب.

## 3. قاعدة العلاقة المؤسسية

وجود جهة في سجل المصادر يعني أنها **مصدر مستقل** فقط، ولا يعني:

- شراكة.
- اعتمادًا.
- مراجعة علمية.
- تأييدًا.
- رعاية.
- موافقة على استخدام الاسم أو الشعار.

لا تُستخدم أي صياغة من هذه الصياغات إلا بعد موافقة مكتوبة تحدد النطاق والمدة والحقوق.

القيمة الآلية الإلزامية في السجل هي:

```text
independent_source_not_partner
```

## 4. حالات الحقوق

### `open_reuse`

يوجد ترخيص مفتوح أو تأكيد مكتوب يسمح بنطاق واضح من النسخ أو الترجمة أو التكييف أو إعادة التوزيع. لا يكفي وجود عبارة «مجاني» أو «مفتوح» دون معرفة الترخيص وشروطه.

### `link_only`

يسمح بالربط إلى المصدر الرسمي، لكن لا يوجد سند كافٍ للنسخ أو الترجمة أو التعديل أو الاستضافة.

### `referral_only`

يُعرض وصف مستقل ومحدود ثم يُحال المستخدم إلى منصة الجهة لإكمال التسجيل أو التعلم أو الحصول على الشهادة. لا تستضيف Psychology Terminology المادة الأصلية.

### `source_specific_review`

تختلف الحقوق بين مخرج وآخر داخل الجهة نفسها؛ لذلك تُراجع صفحة المصدر والترخيص لكل مادة قبل استخدامها.

### `commercial_agreement_required`

الربط قد يكون متاحًا، لكن الترجمة أو الترخيص أو إعادة الاستعمال تتطلب اتفاقًا أو موافقة تجارية مكتوبة.

## 5. قيم الصلاحيات

يستخدم السجل القيم التالية فقط:

- `allowed`: يوجد سند واضح يسمح بالفعل ضمن الشروط المسجلة.
- `not_allowed`: يوجد منع واضح ضمن النطاق الحالي.
- `permission_required`: لا ينفذ الفعل قبل موافقة مكتوبة.
- `not_confirmed`: لم يتوفر سند كافٍ، ويعامل عمليًا كمنع حتى التحقق.
- `not_available`: أفادت الجهة بأن الوظيفة أو المسار غير متاح، مثل عدم وجود تغذية آلية.

## 6. بوابة إدخال مصدر جديد

لا ينتقل المصدر إلى حالة قابلة للاستخدام إلا بعد تسجيل:

1. الاسم الرسمي والرابط الأصلي.
2. نوع المادة والجمهور المستهدف.
3. حالة الحقوق.
4. الترخيص ورابطه، إن وجد.
5. الصلاحيات لكل من الربط والنسخ والترجمة والتكييف وإعادة التوزيع والتضمين والاستعمال التجاري والشعار والتغذية الآلية.
6. متطلبات الإسناد والمشاركة بالمثل وبيان التعديلات.
7. مصدر الدليل الحقوقي وتاريخه.
8. تاريخ المراجعة القادمة.
9. القيود المتعلقة بمواد الأطراف الثالثة.

## 7. قاعدة النشر

يُمنع نشر عمل مشتق عندما تكون صلاحية `translate` أو `adapt` أو `redistribute` مساوية لإحدى القيم التالية:

```text
not_allowed
permission_required
not_confirmed
not_available
```

الربط إلى الصفحة الرسمية لا يجيز تلقائيًا:

- نسخ الوصف الأصلي كاملًا.
- تنزيل الفيديو أو إعادة رفعه.
- إعادة نشر الاختبارات أو الإجابات.
- استخدام الشعار.
- ترجمة المادة.
- تضمين مشغل أو وحدة تعليمية.

## 8. الإسناد

كل مادة معاد استخدامها يجب أن تعرض بوضوح:

- اسم المصدر.
- عنوان المادة الأصلية.
- الرابط الرسمي.
- اسم الترخيص ورابطه.
- المؤلف أو الجهة المنتجة عندما يتوفر.
- تاريخ الوصول أو النسخة.
- بيانًا بالتغييرات أو الترجمة.
- اسم المترجم والمراجع عند النشر بالعربية.

### قالب إسناد أساسي

> المصدر: [اسم الجهة]، [عنوان المادة]، [الرابط]. استُخدمت/تُرجمت/عُدلت وفق [اسم الترخيص ورابطه]. التعديلات: [وصف موجز]. تاريخ الوصول: [التاريخ].

يعدل القالب وفق متطلبات الترخيص المحدد، ولا يحل محل النص القانوني الأصلي.

## 9. الترجمة والتكييف

قبل بدء الترجمة يجب:

1. تأكيد السماح بالترجمة.
2. تحديد ما إذا كانت الترجمة عملًا مشتقًا خاضعًا للمشاركة بالمثل.
3. فصل النصوص والصور والجداول التي قد تخضع لحقوق مختلفة.
4. حفظ النسخة الأصلية وتاريخ الوصول.
5. إجراء مراجعة لغوية وعلمية بشرية.
6. بيان أن الترجمة غير رسمية عندما لا تعتمدها الجهة الأصلية.
7. عدم تغيير المعنى السريري أو درجة اليقين أو التحذيرات.

## 10. الدورات والشهادات

عند فهرسة دورة خارجية يجب أن يوضح الإدراج:

- الجهة المقدمة.
- اللغة.
- المدة والمستوى إن كانا معلنين.
- السعر أو المجانية وقت التحقق.
- متطلبات التسجيل.
- حالة الشهادة أو الاعتماد كما تعلنها الجهة.
- الدولة أو الأهلية الجغرافية إن كانت محددة.
- تاريخ آخر تحقق.

لا يعني إدراج الدورة أن Psychology Terminology:

- تقدمها.
- تعتمدها.
- تضمن استمرارها.
- تضمن الاعتراف المهني بشهادتها في بلد المستخدم.

## 11. البيانات الوصفية وواجهات API

لا تُستهلك تغذية آلية أو API قبل التحقق من:

- شروط الخدمة.
- حدود الطلبات.
- الترخيص.
- حق التخزين المؤقت.
- متطلبات النسبة.
- سياسة التحديث والحذف.
- معالجة البيانات الشخصية.

عندما لا توجد تغذية رسمية، لا يُستخدم الكشط الآلي بديلًا غير مصرح به.

## 12. الشعارات والعلامات

قيمة `logo_use` يجب أن تكون `allowed` بناءً على تصريح واضح قبل عرض شعار الجهة. الإسناد النصي والرابط لا يساويان إذنًا باستخدام العلامة.

## 13. المراجعة الدورية

- المصادر المفتوحة المؤكدة: مراجعة كل ستة أشهر على الأقل.
- الدورات والبوابات المتغيرة: مراجعة كل ثلاثة أشهر على الأقل.
- المواد الحساسة أو ذات الشروط المتغيرة: مراجعة قبل كل استعمال جديد.
- عند تغير الترخيص أو الرابط أو الملكية: إيقاف الاستعمال المشتق حتى اكتمال المراجعة.

## 14. التصحيحات والنزاعات

عند ورود اعتراض حقوقي:

1. تعليق المادة محل الاعتراض أو عزلها عن الفهرسة عند الحاجة.
2. حفظ سجل للحالة دون نشر بيانات شخصية أو مراسلات خاصة.
3. مراجعة المصدر والترخيص ودليل الإذن.
4. التصحيح أو الإزالة أو طلب الترخيص.
5. توثيق القرار وتاريخه ونطاقه.
6. منع عودة المادة تلقائيًا من خطوط البناء أو النسخ القديمة.

## 15. الخصوصية ودليل الإذن

يسجل المستودع خلاصة غير حساسة فقط، مثل نوع التأكيد وتاريخه ونطاقه. لا تنشر:

- روابط تفعيل خاصة.
- معرفات رسائل البريد الداخلية.
- بيانات دخول.
- مراسلات سرية.
- ملفات تعاقدية غير مخصصة للنشر.

يُحفظ الدليل الكامل في نظام وصول مقيد عند توفره، ويربط بالسجل عبر معرف داخلي غير كاشف.

## 16. المسؤوليات

- **التحرير:** تقييم ملاءمة المصدر ودقة العرض.
- **المراجعة العلمية:** التحقق من المعنى ودرجة الدليل.
- **الحقوق:** تحديد ما يسمح به الترخيص أو الإذن.
- **التقنية:** تطبيق القيود آليًا ومنع النشر غير المصرح به.
- **المالك:** الموافقة على الاتفاقات أو الالتزامات المالية أو استخدام العلامات.

## 17. الاختبار الآلي

يتحقق `scripts/validate_source_rights_registry.py` من:

- صحة البنية.
- تفرد المعرفات.
- الروابط الرسمية الآمنة.
- القيم المسموح بها للحالات والصلاحيات.
- وجود ترخيص في حالة `open_reuse`.
- منع صلاحيات النسخ المفتوحة ضمن حالة `link_only` أو `referral_only`.
- ثبات وصف العلاقة على أنها مصدر مستقل لا شريك.
- وجود دليل وتاريخ مراجعة لكل سجل.

نجاح الاختبار لا يمثل رأيًا قانونيًا أو شهادة امتثال؛ بل يمنع التناقضات الواضحة داخل سجل المنصة.
