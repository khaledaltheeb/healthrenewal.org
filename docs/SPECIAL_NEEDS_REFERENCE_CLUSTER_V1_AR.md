# عنقود المراجع الأساسية لذوي الاحتياجات الخاصة — v1

تاريخ الإصدار: 2026-08-13

## الهدف

إضافة طبقة مرجعية عربية عالية القيمة بين المركز العام والأدلة العملية الدقيقة. لا تُنشأ صفحة لكل مرادف بحثي؛ بل تُدمج الاستعلامات المتقاربة في مرجع واحد عندما تكون نية المستخدم واحدة.

## الصفحات الأولى

- التوحد أم ADHD: التشخيص التفريقي والتداخل.
- التوحد لدى البنات والنساء: التمويه والتشخيص المتأخر.
- تأخر الكلام أم اضطراب اللغة النمائي أم التوحد.
- التواصل المعزز والبديل AAC.
- عسر القراءة أم ضعف القراءة.
- UDL والتعليم الدامج.
- IEP والأهداف القابلة للقياس ومتابعة التقدم.
- التدخل المبكر قبل اكتمال التشخيص.

## عقد الجودة

كل صفحة تحتوي على نية مستقلة، وصف Meta، canonical، بيانات منظمة، أسئلة تقييم، خطوات عملية، تصحيح مفاهيم، حدود استخدام وسلامة، ومراجع أصلية. الحالة التحريرية: مراجعة داخلية مصدرية؛ لا يُدعى وجود مراجعة سريرية بشرية مستقلة.

## النشر

ينفذ `scripts/publish_special_needs_reference_cluster_v1.py` داخل artifact الإنتاج، ثم تُكتشف المسارات بواسطة مولد sitemap النهائي. الاختبار: `python -m unittest -v tests.test_special_needs_reference_cluster_v1`.
