# بوابة النشر الإنتاجي لأدلة الرعاية v400

التاريخ: 2026-08-15

## الهدف

منع اعتبار موجة أدلة الرعاية v400 منشورة ما لم تكن صفحاتها المادية موجودة في `_site` ومكتشفة في خريطة الموقع الإنتاجية.

## الخلل الذي كُشف

أظهر تشغيل Production #120 أن ناشر أدلة الرعاية كوّن 235 صفحة HTML تحت `care-guides` بينما كان sitemap الخاص بالناشر يحتوي 151 مسارًا فقط. أدى ذلك إلى إيقاف البناء بدل نشر نسخة ناقصة أو غير متسقة.

## الإصلاح

تم تعديل اكتشاف صفحات أدلة الرعاية بحيث يعتمد على الصفحات المادية الموجودة بعد دمج المصدر الحالي مع baseline، ثم تُبنى خريطة الموقع على كامل السطح المنشور. أضيف اختبار regression مستقل للحالة التي كشفت الخلل.

## عقد القبول

لا يُعتبر v400 صالحًا للنشر إلا عند تحقق ما يلي معًا:

- إصدار المحتوى 400 أو أحدث.
- وجود 50 إضافة في Wave 001.
- 50 slug فريدًا و50 عنوانًا فريدًا للموجة.
- 151 source guide على الأقل و150 دليلًا منشورًا على الأقل.
- وجود مصدر موثوق واحد على الأقل لكل دليل في الموجة.
- تطابق صفحات `care-guides` المادية مع المسارات التي تدخل sitemap الإنتاجي.
- عدم فقد الصفحات القديمة المفيدة المستعادة من baseline.
- مرور بناء Production الكامل قبل إنشاء `validated-production-site` وPages artifact.

## حالة الاعتماد

هذا الملف يوثق البوابة فقط. لا تُسجل حالة "منشور ومتحقق حيًا" إلا بعد نجاح Workflow الإنتاجي، إنشاء artifact جديد، نشر GitHub Pages، ثم التحقق من الصفحات والمخرجات الآلية على `healthrenewal.org`.
