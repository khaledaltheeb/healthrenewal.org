# دليل تعديل الأطباء والمراكز — v308

## الملف الوحيد المطلوب تعديله

`content/v302/special-needs-providers-ar.json`

لا يلزم تعديل HTML أو قوالب الصفحات أو ملفات Python لإضافة طبيب أو مركز جديد.

## خطوات إضافة سجل

1. انسخ الكائن الموجود تحت `example_not_published`.
2. ألصقه داخل قائمة `providers`.
3. غيّر `id` إلى معرّف فريد مثل `jo-amman-center-001`.
4. عبّئ الاسم والنوع والتخصصات والخدمات والدولة والمدينة والعنوان.
5. أدخل الهاتف في `phone_uri` بصيغة دولية من أرقام فقط بعد علامة الجمع، مثل `+962790000000`.
6. أضف روابط الموقع والخريطة وواتساب بصيغة HTTPS.
7. أضف جهة الترخيص ورقم الترخيص أو التسجيل.
8. أضف رابطًا رسميًا واحدًا على الأقل داخل `verification_evidence` يثبت الهوية أو التسجيل أو الترخيص.
9. سجّل تاريخ التحقق وتاريخ آخر تأكيد للاتصال وتاريخ انتهاء صلاحية التحقق.
10. اترك `published` بقيمة `false` و`verification_status` بقيمة `pending` أثناء المراجعة.
11. بعد اكتمال التحقق غيّر `verification_status` إلى `verified` و`published` إلى `true`.

## قواعد النشر

- لا يظهر أي سجل غير موثق أو منتهي الصلاحية.
- لا ينشر سجل بلا جهة ترخيص ورقم تسجيل ودليل تحقق رسمي.
- يجب أن يكون تاريخ آخر تأكيد للاتصال حديثًا، وألا يتجاوز تاريخ انتهاء التحقق.
- السجل المنتهي يجب تحديثه أو تحويله إلى `expired` وإيقاف نشره.
- الإدراج التحريري يستخدم `listing_disclosure: editorial` و`sponsored: false`.
- نشر السجلات الممولة معطل حاليًا بالكامل إلى أن تعرض بطاقة الصفحة علامة «ممول» بصورة ظاهرة وغير ملتبسة.
