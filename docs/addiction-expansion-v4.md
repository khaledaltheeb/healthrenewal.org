# توسعة الإدمان v4: الفئات الإضافية والمواد والسلوكيات الناشئة

تضيف هذه الموجة ستة أدلة للفئات الخدمية والسكانية وثمانية ملفات للمواد والسلوكيات الناشئة.

## مبادئ غير قابلة للتفاوض

- لا يساوي الاستخدام الكثيف تشخيصًا تلقائيًا.
- يعلن كل ملف ناشئ حالة التصنيف وحدود الدليل.
- اضطراب السلوك الجنسي القهري يعرض وفق تصنيف ICD-11 كاضطراب تحكم بالاندفاع، لا كإدمان تلقائي.
- لا توجد فئة عامة واحدة باسم إدمان الإنترنت لكل الاستخدامات؛ اضطراب الألعاب منفصل.
- الشراء القهري يحتاج تقييمًا تفريقيًا ولا يقدم كتشخيص إدماني مستقر.
- لا جرعات أو خفض دوائي أو إزالة سموم منزلية أو وصفات هرمونية.
- الطوارئ والعنف وحماية الأطفال والعدوى والجرعة الزائدة تتقدم على بقية المحتوى.
- التوطين القانوني والخدمي والمراجعة السريرية الخارجية ما زالت مطلوبة.
