# وكيل جودة الموقع والبحث المرجعي v410

## الهدف

الوكيل `scripts/site_quality_agent_v410.py` يمر على صفحات HTML العامة في المستودع أو على artifact الإنتاج الموثق، ويحوّل الفحص إلى طابور ترقية شامل بدل العمل على عينات متفرقة.

## نطاق التدقيق

لكل صفحة يفحص: العنوان وH1، اللغة وRTL، meta description وcanonical وJSON-LD، عمق النص، الروابط الداخلية، الصور و`alt`، hero ذي الخلفية دون لون نص صريح، وجود مصادر خارجية ومصادر من نطاقات علمية/رسمية معروفة، واللغة الصحية المفرطة أو القطعية.

ويفحص ملفات CSS العامة بحثًا عن أزواج `color/background` الصلبة التي تقل عن نسبة تباين 4.5:1، قواعد hero التي تحتاج مراجعة computed-style، وأحجام الخط الأقل من 12px. الفحص الساكن لا يدعي تغطية gradients أو الصور أو inheritance؛ تبقى فحوص Axe/Lighthouse الموجودة في المستودع هي المرجع للحالة المحسوبة داخل المتصفح.

## البحث المرجعي

عند تشغيل `--research` ينشئ الوكيل dossier للصفحات المختارة من:

- PubMed/NCBI E-utilities، مع تقييد البحث إلى مراجعات منهجية وتحليلات تلوية وإرشادات وتجارب عشوائية ومراجعات.
- Crossref للـ DOI والبيانات الببليوغرافية ونوع المنشور وعدد الاستشهادات المسجل.
- أهداف بحث صريحة في المواقع الرسمية WHO وNICE وCDC وNIH وUNICEF وUNESCO.

نتائج البحث مرشحة وليست إثباتًا. قبل تعديل أي ادعاء صحي يجب التحقق من صلة المصدر بالادعاء نفسه، السكان، تصميم الدراسة، الحداثة، القيود، واتساقه مع الإرشادات.

## تغطية مستمرة

الـ workflow يعمل كل 6 ساعات. نصف حصة البحث تقريبًا يبقى لأعلى الصفحات أولوية، والنصف الآخر يدور على بقية الصفحات باستخدام `GITHUB_RUN_NUMBER`، بحيث لا يبقى النظام عالقًا في نفس الصفحات إلى الأبد.

كما أن هناك مسارين منفصلين:

1. تدقيق صفحات المصدر العامة في المستودع.
2. بعد نجاح `Validate every assessment and cognitive tool v31` يتم تنزيل `validated-production-site` نفسه وتدقيقه، حتى يكون الحكم على الناتج الذي سيُنشر وليس على افتراض أن المصدر يطابق الإنتاج النهائي.

## المخرجات

في `artifacts/site-quality-agent-v410/`:

- `report.json`: التقرير الكامل والسياسات وإحصاءات التصميم والمحتوى.
- `upgrade-queue.json`: جميع الصفحات مرتبة حسب أولوية الإصلاح والترقية.
- `research-dossiers.json`: ملفات البحث للصفحات التي دخلت دورة البحث الحالية.

## التشغيل

```bash
python scripts/site_quality_agent_v410.py .
python scripts/site_quality_agent_v410.py . --research --research-limit 60 --per-provider 5
python scripts/site_quality_agent_v410.py validated-site --research --research-limit 60
```

متغيرات البيئة الاختيارية: `RESEARCH_CONTACT_EMAIL` و`NCBI_API_KEY`.

## قاعدة التحرير

هذا الوكيل لا يعيد كتابة ادعاءات طبية أو نفسية تلقائيًا من نتائج البحث. التسلسل الصحيح هو: اكتشاف النقص → تحديد سؤال الصفحة → البحث في الدراسات والكتب والمواقع الرسمية → التحقق من قوة الدليل وحدوده → كتابة ترقية عربية مستقلة وعميقة → ربط الادعاءات بالمراجع المناسبة → إعادة فحص SEO والروابط والتباين وتجربة القراءة قبل الدمج.
