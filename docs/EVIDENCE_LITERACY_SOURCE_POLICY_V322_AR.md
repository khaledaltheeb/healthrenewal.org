# سياسة المصادر والتفسير لمكتبة الثقافة العلمية v322

- تعتمد الصفحات على المصادر المنهجية الأصلية أو الجهات الحافظة للأدوات والإرشادات.
- لا تنسخ قوائم PRISMA أو STROBE أو AGREE كاملة؛ تشرح غرضها وحدود استخدامها وتحيل إلى النسخة الأصلية.
- لا تستخدم قائمة الإبلاغ بوصفها درجة لجودة الدراسة.
- لا تصف المراجعة المنهجية أو التحليل التلوي بوصفهما مرتفعَي اليقين تلقائيًا.
- تفصل بين خطر التحيز داخل الدراسة ويقين جسم الدليل وقوة التوصية.
- تعرض عدم اليقين وفاصل الثقة والأثر المطلق وقابلية التطبيق.
- لا تحول توصية سكانية إلى قرار فردي دون القيم والموارد والحالات المصاحبة والبدائل.
- لا تدعي اكتمال مراجعة منهجية خارجية مستقلة.
