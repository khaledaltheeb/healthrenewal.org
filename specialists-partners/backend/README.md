# Specialist Sector Gateway

طبقة خلفية مستقلة لقطاع المختصين والشراكات المهنية. صُممت لتعمل خلف موقع GitHub Pages دون وضع البريد الخاص أو مفاتيح الخدمات في ملفات الموقع العامة.

## الوظائف

- استقبال طلبات انضمام المختصين والمراكز وإرسال نسخة إلى إدارة المنصة.
- حفظ الطلب برقم متابعة داخل Cloudflare D1.
- إنشاء محادثة خاصة بين الزائر والمختص.
- إرسال إشعار بريدي للمختص والزائر وإدارة المنصة.
- روابط وصول عشوائية، مع تخزين بصمة SHA-256 فقط وانتهاء صلاحية تلقائي.
- حماية Turnstile، وحدود يومية حسب بصمة عنوان الاتصال، وسجل تدقيق.
- سجل عام حي للمختصين لا يعرض إلا الملفات المنشورة والموثقة وذات الموافقة السارية.
- لوحة مالك لإضافة الملف، مراجعته، اعتماده، نشره، تعليقه، سحب الموافقة، وأرشفته.
- جلسات إدارة قصيرة بصلاحيات `owner` و`reviewer` و`moderator` بدل تكرار المفتاح طويل الأجل.
- تاريخ إصدارات غير قابل للاستبدال لكل تعديل على الملف العام.
- عدم دعم المرفقات في النسخة الأولى لتقليل مخاطر تسرب الوثائق الحساسة.

## النشر

1. أنشئ Cloudflare Worker وقاعدة D1.
2. انسخ `wrangler.toml.example` إلى `wrangler.toml` وأدخل معرف قاعدة D1.
3. نفّذ الترحيل:

```bash
wrangler d1 execute pterminology-specialists --remote --file=migrations/0001_initial.sql
```

4. أضف الأسرار:

```bash
wrangler secret put RESEND_API_KEY
wrangler secret put TURNSTILE_SECRET
wrangler secret put ADMIN_API_KEY
# اختياريان لتفويض أدوار محدودة:
wrangler secret put REVIEWER_API_KEY
wrangler secret put MODERATOR_API_KEY
```

5. تحقق من نطاق إرسال البريد لدى مزود البريد، ثم اضبط `FROM_EMAIL`.
6. انشر العامل:

```bash
wrangler deploy
```

7. ضع رابط العامل العام ومفتاح Turnstile العام داخل:

```text
specialists-partners/assets/runtime-config.js
```

## إضافة مختص واعتماد ملفه

استخدم المسار `/specialists-partners/admin/`. يرسل مفتاح المالك مرة واحدة إلى
`POST /v1/admin/session` لإنشاء جلسة قصيرة، ثم تمسحه الواجهة فورًا. من داخل
اللوحة:

1. افتح طلب الانضمام في محرر الاعتماد، أو أنشئ ملفًا يدويًا.
2. أكمل الحساب الخاص والملف العام.
3. راجع الهوية والمؤهل والنطاق والترخيص أو التسجيل ووسائل التواصل.
4. سجل الموافقة الكتابية ومصادر التحقق وموعد المراجعة القادمة.
5. استخدم «حفظ كمسودة» أو «إرسال للمراجعة».
6. لا يظهر الملف للعامة إلا بعد «اعتماد ونشر».

البريد الخاص وملاحظات المراجعة لا تدخل `profile_json` العام.

## متغيرات البيئة

| المتغير | الغرض |
|---|---|
| `DB` | ربط قاعدة D1 |
| `OWNER_EMAIL` | البريد الذي يستقبل طلبات الانضمام وإشعارات الإدارة |
| `RESEND_API_KEY` | مفتاح إرسال البريد |
| `FROM_EMAIL` | عنوان إرسال موثّق |
| `TURNSTILE_SECRET` | التحقق الخادمي من Turnstile |
| `ADMIN_API_KEY` | حماية مسارات الإدارة |
| `REVIEWER_API_KEY` | مفتاح اختياري لمراجع يستطيع بدء المراجعة دون النشر |
| `MODERATOR_API_KEY` | مفتاح اختياري لمشرف المحادثات دون صلاحية الملفات |
| `ADMIN_SESSION_MINUTES` | مدة الجلسة القصيرة، من 5 إلى 60 دقيقة |
| `ALLOWED_ORIGINS` | النطاقات المسموح لها باستدعاء الواجهة |
| `PORTAL_BASE_URL` | رابط بوابة المحادثة في الموقع |
| `RATE_LIMIT_SALT` | قيمة سرية لبصمة عناوين الاتصال |

## الحدود التشغيلية الحالية

- روابط الوصول صالحة لمدة 90 يومًا، وتُنقل في URL fragment ثم تزال من شريط العنوان.
- لا توجد مرفقات، مكالمات، دفع، مواعيد، أو تشخيص آلي.
- يلزم قبل التوسع الكبير اعتماد سياسة احتفاظ قانونية محلية، ومسار تصدير/حذف موثق، وخطة استجابة للحوادث واختبار استعادة دوري.
