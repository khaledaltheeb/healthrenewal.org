الإدمان والتعافي

مسار مستقل لفهم اضطرابات استخدام المواد، تقليل الضرر، العلاج والتعافي، السلامة، الأسرة، والعودة إلى الأدوار اليومية مع محتوى تعليمي ومقارنات وموارد قابلة للتتبع.

لا تختزل روافد التعافي في الامتناع وحده؛ تُقرأ النتائج مع الصحة الجسدية والنفسية والسكن والعمل والعلاقات والمشاركة وجودة الحياة.

فتح قطاع الإدمان والتعافي

متى تربطه بقطاع آخر؟

  • مع الصحة النفسية عند وجود اكتئاب أو قلق أو صدمة أو خطر.
  • مع التأهيل عند وجود إصابة أو ألم أو ضعف وظيفي أو عودة للعمل.
  • مع الأسرة عندما تكون العلاقات والرعاية جزءًا من خطة التعافي.
  • مع خدمات الطوارئ عند الجرعة الزائدة أو التسمم أو الخطر الحاد.

افحص الوظيفة والسلامة

ما الذي تعطل؟ وهل يوجد خطر مباشر؟ الخطر يسبق التصفح، والوظيفة تساعد على قياس شدة الأثر.

أضف القطاع الثاني فقط عند وجود سبب

مثل اضطراب استخدام مادة مع اكتئاب، أو سكتة دماغية مع تغير مزاجي، أو طفل مع صعوبة نفسية وضغط أسري. لا تفتح كل المسارات احتياطًا.

وحّد الأهداف والقياس

إذا تعددت الخدمات، اجعل لكل تدخل هدفًا واضحًا ومؤشر متابعة وموعد مراجعة بدل خطط متوازية لا تتحدث مع بعضها.

السلامة لا تتبع حدود القطاعات

عند خطر انتحار أو عنف، جرعة زائدة أو تسمم، فقد وعي، ارتباك/ذهان حاد، أعراض طبية أو عصبية جديدة شديدة، إساءة أو إهمال خطير، أو عجز عن تلبية الاحتياجات الأساسية: استخدم خدمات الطوارئ أو الحماية أو الرعاية الصحية المحلية المناسبة. لا تعتمد على اختبار أو صفحة تثقيفية لاتخاذ قرار عاجل.
