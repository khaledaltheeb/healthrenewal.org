قياس النتائج ← الطرف العلوي واليد

Upper limb · hand function

قوة اليد ليست هي وظيفة اليد

التقييم المتوازن للطرف العلوي يربط القوة بالمهارة وباستخدام اليد في المهمة الحقيقية: الأكل، اللبس، الكتابة، الهاتف، العمل، حمل الأشياء أو استخدام طرف صناعي.

حزمة القياس

قوة القبضة

مفيدة عندما تكون القوة جزءًا من السؤال السريري. ثبّت وضعية الطرف والجهاز واليد المختبرة، ولا تعتبر تحسن القوة دليلًا تلقائيًا على تحسن المهارة.

ورقة قوة القبضة

مهارة خشنة

يمكن أن يُستخدم Box and Block عندما يناسب التشخيص والهدف، لكننا نحيل إلى بروتوكوله الرسمي ولا نعيد نشر مواد الاختبار أو جداول المعايير.

مهارة دقيقة

Nine-Hole Peg Test مثال شائع للمهارة الدقيقة، وهو غير مجاني وفق Rehabilitation Measures Database؛ لذلك لا ننشئ نسخة بديلة غير مرخصة.

مهمة ذات معنى

اختر مهمة يومية قابلة للتكرار: أزرار، كوب، قلم، أداة عمل، لوحة مفاتيح أو نشاط ثنائي اليدين، وسجل نوع المساعدة والزمن أو الجودة.

لا تخلط بين القدرة والاستخدام

قد ينجح الشخص في اختبار قصير داخل العيادة لكنه لا يستخدم اليد في المنزل بسبب الألم أو التعب أو الخوف أو بطء المهمة أو البيئة. لذلك أضف دائمًا سؤالًا عن الاستخدام الفعلي والمشاركة.

إعادة القياس

ثبّت اليد المختبرة والوضعية والأداة والتعليمات قدر الإمكان. بعد جراحة جديدة أو ألم شديد متزايد أو تورم حاد أو ضعف عصبي جديد، الأولوية لإعادة التقييم السريري لا لمقارنة الزمن أو القوة فقط.
