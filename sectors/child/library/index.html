ابحث حسب الوظيفة والسياق لا حسب التشخيص فقط

المكتبة الموضوعية للصحة النفسية للطفل

تنظم هذه المكتبة الموضوعات التي يلاحظها الأهل والمدرسة والطفل نفسه. كل محور يوضح ما الذي يستحق الملاحظة، وما العوامل الأخرى التي قد تشبهه، وما المعلومات التي ينبغي جمعها قبل الانتقال إلى التقييم أو التدخل.

الانتقال لمسار التقييممراجعة التدخلات

طريقة الاستخدام

  1. اختر الوظيفة المتأثرة أولًا.
  2. حدد العمر والسياق والمدة.
  3. راجع العوامل الصحية والنمائية والبيئية.
  4. اجمع أمثلة لا أوصافًا عامة.
  5. صعّد عند الخطر أو التعطل المستمر.

هذه المكتبة ليست قائمة تشخيص ذاتي

تشابه الأعراض شائع؛ فقد يظهر القلق كتجنب أو ألم بطن، وقد يظهر اضطراب النوم كتشتت أو غضب، وقد تؤثر صعوبات اللغة أو التعلم أو الألم في السلوك. لا تُستخدم بطاقة واحدة للحكم على الطفل.

1. المشاعر والتنظيم الانفعالي

نبحث في شدة المشاعر ومدتها والقدرة على العودة إلى الهدوء والأثر في الحياة، لا في وجود الغضب أو الخوف أو الحزن وحده.

القلق والخوف

التجنب والطمأنة والشكاوى الجسدية

قد يظهر القلق كالتصاق بالوالد، أو رفض مدرسة، أو أسئلة متكررة، أو صمت، أو ألم بطن. افحص التنمر والانفصال والمرض والتغيرات الحديثة.

  • ما الموقف الذي يسبق الخوف؟
  • هل يخف بعد التجنب؟
  • هل يمنع نشاطًا مناسبًا للعمر؟
المزاج

الحزن وفقد المتعة والانسحاب

لا يظهر الاكتئاب دائمًا كحزن معلن؛ قد يظهر كتعب أو تهيج أو تراجع دراسي أو فقد اهتمام. يلزم سؤال مناسب للعمر عن اليأس وإيذاء النفس.

  • هل فقد الطفل متعته المعتادة؟
  • ما مدة التغير؟
  • هل تغير النوم أو الشهية أو الطاقة؟
الغضب

الانفجارات وصعوبة التهدئة

ابحث في المحفزات والطلبات واللغة والحواس والجوع والتعب والمهارات المتاحة. العقاب وحده قد يزيد التصعيد إذا كانت المشكلة نقص مهارة أو حملًا زائدًا.

  • ما الذي يحدث قبل الانفجار؟
  • كيف ينتهي؟
  • ما المهارة التي لا يستطيع استخدامها؟

2. الانتباه والاندفاع والسلوك التنفيذي

التشتت والاندفاع قد يرتبطان بالنمو أو اضطراب النوم أو القلق أو صعوبة التعلم أو بيئة غير مناسبة أو حالة نمائية. يلزم النظر عبر أكثر من سياق.

الانتباه وبدء المهمة

ميّز بين عدم الفهم وعدم القدرة على البدء وعدم تحمل المهمة وفقد الدافعية. راقب نوع المهمة ومدتها ومستوى الدعم.

الاندفاع والنشاط

افحص الأمان والانتظار وتقدير العواقب، وهل يظهر النمط في المنزل والمدرسة واللعب، وهل يختلف مع النشاط المفضل.

الذاكرة العاملة والتنظيم

نسيان الخطوات وفقد الأدوات وتأخر الانتقال قد يحتاج تعليمات قصيرة وروتينًا مرئيًا وتخفيف عدد الخطوات، لا تكرار اللوم.

3. النوم والأكل والأعراض الجسدية

النوم

سجل وقت النوم والاستيقاظ والاستغراق والاستيقاظ الليلي والشخير والكوابيس والأجهزة والكافيين والأدوية. اضطراب النوم قد يفاقم المزاج والانتباه والسلوك.

الأكل وصورة الجسد

التغير السريع في الشهية أو الوزن، والخوف من الطعام، والقيء المتعمد، والإفراط في الرياضة أو الإغماء تستحق تقييمًا صحيًا عاجلًا بحسب الشدة.

الصداع وألم البطن والتعب

لا تفترض أن العرض نفسي. يلزم تقييم صحي مناسب، مع ملاحظة ارتباط الأعراض بالمدرسة أو الضغط أو الطعام أو النوم أو الدورة اليومية.

4. المدرسة والتعلم والعلاقات

رفض المدرسة أو الغياب

حدد هل الصعوبة في مغادرة المنزل أو النقل أو بوابة المدرسة أو صف بعينه. افحص التنمر والقلق والتعلم والحواس والعلاقة مع المعلم.

التراجع الدراسي

قد يعكس صعوبة نوعية في القراءة أو الكتابة أو الحساب، أو مشكلة بصرية أو سمعية، أو ضغطًا نفسيًا، أو نقص حضور، أو اضطراب نوم.

الصداقة والتنمر والعزلة

اسأل عن الأمان والانتماء والتواصل والتنمر المباشر والرقمي. لا تفسر العزلة دائمًا كاختيار أو ضعف مهارة اجتماعية فقط.

5. التواصل والنمو العصبي والاحتياجات الخاصة

اللغة والتواصل

صعوبة التعبير أو فهم اللغة قد تظهر كسلوك أو انسحاب أو إجابات غير متوقعة. افحص السمع واللغة والتواصل البديل عند الحاجة.

الحواس والمرونة

الضوضاء والضوء والملمس والتغير المفاجئ قد ترفع الحمل. صف المثير والاستجابة والوقت اللازم للتعافي بدل وصف الطفل بالمبالغة.

فقد المهارات أو التراجع

فقد لغة أو حركة أو استقلال أو مهارة مكتسبة يحتاج تقييمًا صحيًا ونمائيًا منظمًا، وقد يكون عاجلًا إذا كان سريعًا أو مصحوبًا بأعراض عصبية.

6. الصدمات والفقد والعنف والسلامة

الفقد والتغيرات الكبرى

الانتقال أو الانفصال أو وفاة شخص أو مرضه قد تظهر آثارها في النوم واللعب والتعلق والسلوك. يحتاج الطفل إلى معلومات صادقة مناسبة للعمر وروتين ودعم.

العنف والإساءة والإهمال

الإفصاح يُؤخذ بجدية. استمع دون استجواب تفصيلي أو لوم، وثّق الكلمات الأساسية، واتبع مسار الحماية المحلي والجهات المؤهلة.

إيذاء النفس والأفكار الانتحارية

لا تعتبرها طلب اهتمام ولا تستخدم مقياسًا رقميًا وحده لتقدير الخطر. يلزم تقييم مباشر للسياق والنية والوسائل والدعم والحماية.

حوّل الموضوع إلى سؤال تقييم

بعد اختيار المحور، اكتب: ما التغير؟ متى بدأ؟ أين يظهر؟ ما أثره؟ ما العوامل الصحية والنمائية والمدرسية والأسرية؟ ثم انتقل إلى مسار التقييم لتحديد مستوى الحاجة.
