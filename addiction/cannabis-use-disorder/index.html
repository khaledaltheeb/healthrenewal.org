اضطراب استخدام القنب

استخدام متكرر للقنب يسبب فقدان السيطرة أو ضررًا وظيفيًا أو نفسيًا أو اجتماعيًا، وقد يترافق مع تحمّل وانسحاب.

ليس كل استخدام اضطرابًا، لكن وصف القنب بأنه طبيعي لا يلغي مخاطر الاعتماد والقيادة المتأثرة والقلق والذهان لدى بعض الأشخاص.

الاسم الإنجليزي: Cannabis Use Disorder · آخر مراجعة منهجية: 3 أغسطس 2026.

التعريف وحدود المفهوم

ما الحالة؟

استخدام متكرر للقنب يسبب فقدان السيطرة أو ضررًا وظيفيًا أو نفسيًا أو اجتماعيًا، وقد يترافق مع تحمّل وانسحاب.

ما الذي لا تعنيه؟

ليس كل استخدام اضطرابًا، لكن وصف القنب بأنه طبيعي لا يلغي مخاطر الاعتماد والقيادة المتأثرة والقلق والذهان لدى بعض الأشخاص.

العلامات وعوامل الخطر

علامات تستحق التقييم

  • محاولات فاشلة للتقليل
  • استخدام متكرر مع تدهور الدراسة أو العمل
  • مشكلات ذاكرة وانتباه أو نوم
  • قلق أو شك أو هلع مرتبط بالاستخدام
  • استمرار رغم القيء أو مشكلات العلاقة

عوامل ترفع التعقيد

  • بدء مبكر ومنتجات عالية التركيز
  • تاريخ شخصي أو عائلي للذهان
  • القيادة أو تشغيل آلات بعد الاستخدام
  • الخلط مع كحول أو مهدئات
  • استخدامه بدل علاج اضطراب نفسي أساسي

وجود علامة واحدة لا يثبت التشخيص. التقييم المهني يجمع النمط والضرر والمدة والوظيفة والمصاحبات.

خريطة العلاج والتعافي

  • مقابلة تحفيزية وCBT وإدارة طوارئ سلوكية
  • خطة نوم ومتابعة أعراض الانسحاب
  • تقييم القلق والاكتئاب والذهان وADHD والصدمات
  • تقييم طبي للقيء المتكرر والجفاف
  • لا دواء واحدًا يضمن العلاج؛ تُراجع الأعراض مع مختص

عشرة بروتوكولات رعاية منظمة

هذه وحدات قرار وتنظيم وليست وصفات فردية. تُكيَّف حسب البلد والقانون والموارد والتقييم السريري.
