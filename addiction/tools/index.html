أدوات قابلة للطباعة

أدوات الأسرة والتعافي العملية

ست أدوات تحول النصائح العامة إلى خطوات مكتوبة ومسؤوليات ومواعيد ومؤشرات طوارئ قابلة للمراجعة.

لا تستبدل الطوارئ أو التقييم الطبي أو النفسي أو القانوني المحلي.

خطة المحادثة الأولى

بدء الحديث دون لوم أو مواجهة خطرة، مع هدف محدد وخطة للرفض والطوارئ.

خطة الحدود المالية والمنزلية

حماية الأطفال والسكن والمال ومنع التمكين والعنف بحدود قابلة للتنفيذ.

خطة الجرعة الزائدة والطوارئ

الاستجابة السريعة وعدم تأخير الإسعاف ومعلومات المنزل الضرورية.

خطة التعامل مع التعثر والانتكاس

تقييم الخطر وفقد التحمل وتعديل العلاج وحماية الأسرة بلا وصمة.

قائمة تقييم مركز العلاج

الترخيص والتقييم والطوارئ والعلاج الدوائي والنتائج والخصوصية والتكاليف.

خطة المتابعة بعد الخروج

24 ساعة و7 أيام و30 و90 يومًا مع العلاج والسكن والنقل ومنع الجرعة الزائدة.

قاعدة الاستخدام

اكتب أسماء ومسؤوليات ومواعيد فعلية. راجع الخطة بعد كل حادث أو انتقال، ولا تستخدم أداة عامة لتحديد جرعة أو خفض دواء أو تنفيذ انسحاب منزلي.
