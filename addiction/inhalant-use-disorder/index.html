التعريف وحدود المفهوم

ما الحالة؟

استخدام مواد متطايرة أو غازات أو بخاخات لإحداث تأثير نفسي، وقد يسبب اضطراب نظم مفاجئًا أو نقص أكسجة أو أذى عصبيًا وعضويًا.

ما الذي لا تعنيه؟

لا توجد جرعة آمنة للاستخدام بغرض النشوة، وقد تحدث وفاة مفاجئة حتى دون تاريخ طويل.

العلامات وعوامل الخطر

علامات تستحق التقييم

  • روائح كيميائية أو بقايا مذيبات
  • طفح حول الفم أو دوار وتلعثم
  • تراجع دراسي أو سلوكي مفاجئ
  • أكياس أو عبوات مخفية واستخدام في أماكن مغلقة
  • مشكلات ذاكرة وتوازن وأعصاب

عوامل ترفع التعقيد

  • المراهقة وسهولة الوصول للمواد
  • أماكن سيئة التهوية ومصادر نار
  • استخدام منفرد أو مع مواد أخرى
  • تشرد أو إساءة أو اضطرابات سلوكية
  • تعرض مهني دون ضوابط

وجود علامة واحدة لا يثبت التشخيص. التقييم المهني يجمع النمط والضرر والمدة والوظيفة والمصاحبات.

خريطة العلاج والتعافي

  • تقييم طبي عاجل عند تسمم أو أعراض قلبية/تنفسية/عصبية
  • إبعاد آمن عن المصدر والاتصال بالطوارئ أو مركز السموم المحلي
  • فحص عصبي وقلبي وكبدي وكلوي ونفسي حسب التعرض
  • علاج سلوكي وأسري وبيئي مع تأمين المواد
  • دعم تعليمي واجتماعي وعلاج المصاحبات

عشرة بروتوكولات رعاية منظمة

للشخص المتأثر

  • ابتعد عن المكان واتصل بالطوارئ عند دوار شديد أو ألم صدر أو صعوبة تنفس
  • الخطر غير قابل للتنبؤ؛ توقف واطلب علاجًا
  • أخبر المختص بالمادة والعبوة وطريقة التعرض

المسار الكامل للشخص

للأسرة وأهل الشخص

  • لا تدخل مكانًا ملوثًا دون أمان ولا تشعل نارًا
  • احتفظ بالعبوة للطوارئ إن كان آمنًا واتصل بالسموم/الإسعاف
  • أمّن المواد وافحص المدرسة والإساءة والصحة النفسية

المسار الكامل للأسرة

للمدرب وميسّر التعافي

  • لا تقدم إسعافًا كيميائيًا خارج تدريبك
  • ركز على الوصول للمواد والبدائل والاتصال بالخدمات
  • صعّد أي أعراض عصبية أو قلبية

حدود الدور والكفاءات

للمجتمع والمؤسسات

  • تخزين وبيع وتهوية وتدريب مهني آمن
  • مسار مدرسي مبكر غير عقابي
  • ربط السموم والطوارئ والصحة النفسية وحماية الطفل
