سلامة الانسحاب: متى لا يكون المنزل مكانًا آمنًا؟

الانسحاب ليس اختبار قوة. القرار يعتمد على المادة، شدة الاعتماد، تاريخ الاختلاجات والهذيان، الأمراض المصاحبة، الحمل، الأدوية، السكن، والدعم المتاح.

الهدف من الصفحة تحديد الحاجة إلى التقييم ومستوى الرعاية، لا كتابة وصفة ذاتية.

اطلب الطوارئ فورًا

صعوبة أو بطء التنفس، عدم الاستجابة، زرقة، اختلاجات، هذيان أو ارتباك شديد، هلوسة مع خطر، ألم صدر، حرارة شديدة، قيء مع جفاف، أفكار انتحارية، أو حمل مع أعراض انسحاب.

مصفوفة الخطورة

الفئةالخطر الأساسيالقاعدة الآمنة
الكحولاختلاجات وهذيان واضطراب نبض وضغطتقييم طبي قبل التوقف عند اعتماد متوسط أو شديد، أو تاريخ انسحاب معقد.
البنزوديازيبينات والمهدئاتاختلاجات وهذيان وانسحاب مطوللا إيقاف مفاجئ بعد استعمال منتظم؛ خفض تدريجي فردي تحت إشراف.
الأفيوناتفقدان التحمل والجرعة الزائدة بعد الانقطاععرض علاج دوائي مستمر ونالوكسون؛ إزالة السموم وحدها غير كافية.
المنشطاتاكتئاب أو انتحار وذهان ومضاعفات قلبيةمراقبة نفسية وطبية، خصوصًا خلال الهبوط والأرق المطول.
القنبقلق ونوم ورغبة؛ ذهان أو قيء شديد لدى بعض الحالاتدعم منظم وتقييم طارئ عند الذهان أو الانتحار أو الجفاف.
النيكوتينرغبة وعصبية وتركيز ونومعلاج سلوكي ودوائي مناسب ومتابعة؛ الانسحاب عادة غير مهدد للحياة.
المستنشقاتسمية قلب ودماغ ورئة وكبد وكلىالتقييم الطبي للتسمم أهم من افتراض أنه انسحاب بسيط.

عوامل ترفع مستوى الرعاية

تاريخ انسحاب شديد

اختلاجات، هذيان، دخول عناية، أو محاولات فاشلة متكررة.

استخدام متعدد

أكثر من مادة، أدوية غير موصوفة، أو عدم معرفة ما تم تناوله.

حالة طبية معقدة

حمل، مرض كبد أو قلب أو تنفس، إصابة دماغية، عمر متقدم، أو عدوى حادة.

خطر نفسي واجتماعي

ذهان، انتحار، عنف، تشرد، غياب شخص داعم، أو عدم الوصول للطوارئ.

كيف يقرر الفريق مستوى الرعاية؟

  1. يحدد أخطر تسمم وأخطر انسحاب، لا المادة «المفضلة» فقط.
  2. يقيم العلامات الحيوية والوعي والصحة النفسية والأمراض المصاحبة.
  3. يراجع كل الأدوية والكحول والمواد الجديدة أو المجهولة.
  4. يحدد قدرة الشخص على تناول السوائل والدواء وحضور المتابعة.
  5. يختار الرعاية الأقل تقييدًا التي تبقى آمنة، مع إمكانية رفع المستوى سريعًا.

لماذا لا توجد جداول جرعات هنا؟

الجداول العامة قد تكون خطرة لأنها تتجاهل نصف العمر والجرعة والمدة ووظائف الكبد والكلى والحمل والتداخلات. بعض الخطط تحتاج مراقبة علامات حيوية وتقييمًا متكررًا وتعديلًا يوميًا.

خطة أمان منزلية عامة بعد موافقة المختص

  • شخص بالغ موثوق يعرف الخطة وعلامات التصعيد.
  • هاتف مشحون ووسيلة نقل وطوارئ معروفة.
  • عدم القيادة أو استخدام آلات خطرة.
  • عدم خلط كحول أو مهدئات أو أفيونات لتسكين الأعراض.
  • سوائل وغذاء حسب الإرشاد، وأدوية فقط كما وصفها المختص.
  • موعد متابعة واضح خلال فترة قصيرة، لا متابعة مفتوحة.

تنبيه طبي: المحتوى لا يستبدل تقييم الطوارئ أو الطبيب.
