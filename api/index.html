API v1 — قراءة عامة دون بيانات شخصية

بيانات منظمة تربط المحتوى بالمواقع والتطبيقات

تتيح الواجهة اكتشاف أقسام المنصة، والوصول إلى فهرس الصفحات القابلة للفهرسة وتصنيفها الموضوعي، وقراءة كتالوج الدورات التي يثبت الإذن بإعادة استخدام بياناتها الوصفية. لا تستقبل الواجهة نتائج صحية أو سجلات مستخدمين أو مواد اختبارات محمية.

اكتشاف المنصة مواصفة OpenAPI فهرس المحتوى التصنيف الموضوعي الدورات المخولة

الاستيراد لا يبدأ قبل ثبوت الإذن

لا تُنشر بيانات دورة خارجية إلا بعد التحقق من هوية مقدمها، ورابط المصدر الأصلي، ونطاق الترخيص، ودليل الإذن، وتاريخ صلاحيته. الكتالوج يعرض البيانات الوصفية المسموح بها فقط، ولا ينسخ الفيديوهات أو الملفات أو الاختبارات أو المواد التدريبية المحمية.

عرض المثال

مثال قراءة فهرس المحتوى

fetch("https://khaledaltheeb.github.io/pterminology-site/api/v1/content-index.json")
  .then(response => {
    if (!response.ok) throw new Error(`HTTP ${response.status}`);
    return response.json();
  })
  .then(index => {
    const autismPages = index.items.filter(page =>
      page.tags.some(tag => tag.includes("التوحد"))
    );
    console.log(autismPages);
  })
  .catch(console.error);

عقد الاستقرار والخصوصية

إصدارات مستقرة

يبقى الإصدار الرئيسي ضمن /api/v1/. تُضاف الحقول بصورة متوافقة، وأي تغيير غير متوافق ينتقل إلى إصدار رئيسي جديد.

لا بيانات شخصية

الاستجابات العامة لا تحتوي على أسماء مستخدمين أو جلسات أو نتائج صحية أو تقارير فردية أو معرفات داخلية للحالات.

المصدر القانوني محفوظ

كل دورة خارجية تحتفظ بالرابط القانوني لمصدرها وإسنادها، ولا تُعرض عند انتهاء الإذن أو فشل التحقق.

لا مواد مهنية محمية

لا تُعرض بنود الاختبارات أو مفاتيح التصحيح أو جداول المعايير أو محتوى الدورات المدفوع أو المحمي.
