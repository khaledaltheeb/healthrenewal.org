API v1

واجهة قراءة عامة وعقد تكامل واضح

تتيح هذه الواجهة اكتشاف أقسام المنصة وقراءة المواصفة التقنية ومخطط بيانات الدورات. جميع النقاط الحالية ثابتة للقراءة ولا تستقبل بيانات شخصية أو نتائج صحية.

بيانات المنصة OpenAPI مخطط الدورات

شرط استيراد الدورات

لا يُسحب أي محتوى أو وصف دورة من جهة خارجية قبل وجود إذن موثق وترخيص يسمح بإعادة استخدام البيانات. يجب الحفاظ على الرابط الأصلي والإسناد، ولا يجوز تجاوز تسجيل الدخول أو القيود التقنية أو إزالة حقوق صاحب المحتوى.

النقاط المتاحة

GET /api/v1/platform.json

اسم المنصة، الموارد، الأقسام، الروابط، وسياسة التكامل.

عرض الاستجابة

GET /api/v1/openapi.json

مواصفة OpenAPI 3.1 لتوليد عميل أو التحقق الآلي من العقد.

عرض المواصفة

GET /api/v1/courses.schema.json

JSON Schema يفرض بيانات مقدم الخدمة والإذن والترخيص والروابط الأصلية.

عرض المخطط

GET /api/v1/courses.example.json

مثال توضيحي فقط؛ لا يمثل دورة حقيقية أو شراكة أو إذنًا قائمًا.

عرض المثال

مثال قراءة

fetch("https://khaledaltheeb.github.io/pterminology-site/api/v1/platform.json")
  .then(response => {
    if (!response.ok) throw new Error(`HTTP ${response.status}`);
    return response.json();
  })
  .then(platform => console.log(platform.resources))
  .catch(console.error);

قواعد الاستقرار

  • الإصدار الرئيسي في المسار: /api/v1/.
  • تُضاف الحقول الجديدة بصورة متوافقة ما أمكن.
  • أي تغيير غير متوافق ينتقل إلى إصدار رئيسي جديد.
  • لا تحتوي الاستجابات العامة على بيانات مستخدمين أو حالات أو جلسات.
  • لا تُقدَّم الأدوات المحمية أو مفاتيح التصحيح أو المواد التدريبية الخارجية عبر الواجهة.
