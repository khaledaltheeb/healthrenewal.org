API v1

واجهة قراءة عامة وعقد تكامل واضح

تتيح هذه الواجهة اكتشاف أقسام المنصة، وقراءة فهارس موارد وجودة وتعليم التقنيات المساعدة، والمواصفة التقنية، ومخطط بيانات الدورات. جميع النقاط الحالية ثابتة للقراءة ولا تستقبل بيانات شخصية أو نتائج صحية.

بيانات المنصة المصادر إطار الجودة التعليم المستمر OpenAPI مخطط الدورات

حقوق المصادر الخارجية ودقة الاعتماد

الفهارس تربط بالمصادر الرسمية وتصف طريقة الاستفادة منها، لكنها لا تعيد نشر المعايير أو أوراق الموقف أو الدورات المحمية، ولا تدعي أن RESNA راجعت المنصة أو اعتمدتها. إدراج مؤسسة كمزود رسمي لا يعني أن جميع دوراتها تمنح وحدات RESNA؛ يجب التحقق من الفعالية المحددة.

النقاط المتاحة

GET /api/v1/platform.json

اسم المنصة، الموارد، الأقسام، الروابط، وسياسة التكامل.

عرض الاستجابة

GET /api/v1/assistive-technology-resources.json

فهرس عربي منظم لمعايير وأخلاقيات وأوراق موقف وتدريب وبحث التقنيات المساعدة، مع قواعد النسبة والاستخدام.

عرض الفهرس

GET /api/v1/assistive-technology-quality-framework.json

مبادئ أخلاقية ومراحل خدمة وبوابات مراجعة ابتكار وإشارات توقف، بصيغة قابلة للقراءة آليًا.

عرض إطار الجودة

GET /api/v1/resna-ce-providers.json

لقطة مؤرخة من مزودي التعليم المستمر الرسميين وحقول التحقق المطلوبة لكل دورة.

عرض دليل التحقق

GET /api/v1/openapi.json

مواصفة OpenAPI 3.1 لتوليد عميل أو التحقق الآلي من العقد.

عرض المواصفة

GET /api/v1/courses.schema.json

JSON Schema يفرض بيانات مقدم الخدمة والإذن والترخيص والروابط الأصلية.

عرض المخطط

GET /api/v1/courses.example.json

مثال توضيحي فقط؛ لا يمثل دورة حقيقية أو شراكة أو إذنًا قائمًا.

عرض المثال

مثال قراءة إطار الجودة

fetch("https://healthrenewal.org/api/v1/assistive-technology-quality-framework.json")
  .then(response => {
    if (!response.ok) throw new Error(`HTTP ${response.status}`);
    return response.json();
  })
  .then(framework => console.log(framework.innovationGates))
  .catch(console.error);

قواعد الاستقرار

  • الإصدار الرئيسي في المسار: /api/v1/.
  • تُضاف الحقول الجديدة بصورة متوافقة ما أمكن.
  • أي تغيير غير متوافق ينتقل إلى إصدار رئيسي جديد.
  • لا تحتوي الاستجابات العامة على بيانات مستخدمين أو حالات أو جلسات.
  • لا تُقدَّم الأدوات المحمية أو مفاتيح التصحيح أو المواد التدريبية الخارجية عبر الواجهة.
  • البيانات المؤرخة التي تعتمد على دليل خارجي تحتاج إعادة تحقق دوري.
