# بروتوكولات التقييم والعلاج والتأهيل — v326

تحتوي الحزمة `special-needs-protocols-ar.parts/` (Base64 + Gzip) على مصدر عربي قابل للتدقيق لخمسين
بروتوكولًا مؤسسيًا. تفرق البروتوكولات بين التشخيص، والملف الوظيفي، والحالة
المصاحبة، وتربط التقييم بالتدخل المتدرج، والنموذج المتقدم والهجين، وقياس النتائج،
وشروط التعديل أو الإيقاف، وعلامات الخطر، والممارسات غير الموصى بها.

## نطاق النشر

- فهرس واحد: `/special-needs/protocols/`.
- خمسون ملفًا مستقلًا تحت `/special-needs/protocols/{slug}/`.
- تقرير قابل للآلة: `/api/special-needs-protocols-v326.json`.
- تسجيل 51 مسارًا في `sitemap-special-needs.xml`.
- ربط واحد قابل لإعادة البناء من مركز ذوي الاحتياجات الخاصة.

## حوكمة الدليل

المصدر يعطي الأولوية لحزم منظمة الصحة العالمية، وإرشادات NICE، ومراجع الجمعيات
المهنية والمصادر الحكومية أو التخصصية الأصلية. المقارنة بين ألمانيا واليابان
وبريطانيا وكندا والولايات المتحدة والصين تميز بين التوصية المباشرة ونموذج الخدمة
القابل للنقل؛ وجود ممارسة في دولة لا يجعلها فعالة تلقائيًا.

المحتوى خضع لمراجعة تحريرية ومنهجية داخلية. المراجعة الخارجية السريرية المستقلة
لم تكتمل، ولا يجوز وصف الحزمة بأنها اعتماد رسمي أو وصفة فردية. لا تتضمن الصفحات
جرعات دوائية شخصية أو قرارات تشخيص أو أهلية.
