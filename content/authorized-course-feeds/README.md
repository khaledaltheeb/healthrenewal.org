# Authorized course feeds

هذا المجلد مخصص حصراً لملفات JSON التي يثبت الإذن بإعادة استخدام بياناتها الوصفية.

## شروط القبول

- هوية مقدم الخدمة ورابط موقعه الرسمي.
- دليل إذن متاح عبر HTTPS، ونطاق ترخيص واضح، وتاريخ تحقق غير مستقبلي.
- عدم انتهاء صلاحية الإذن.
- رابط قانوني أصلي لكل دورة ورابط تسجيل رسمي.
- `rights.metadataReuse` يساوي `true`.
- عدم تضمين فيديوهات أو ملفات أو اختبارات أو مفاتيح تصحيح أو مواد تدريبية محمية.

## الصيغة

استخدم العقد المنشور في:

```text
api/v1/courses.schema.json
```

ويمكن مراجعة المثال البنيوي في:

```text
api/v1/courses.example.json
```

كل ملف منتهي بـ `.json` داخل هذا المجلد يُعامل كتغذية إنتاجية، لذلك لا تُحفظ أمثلة أو مسودات هنا. عند غياب أي تغذية مخولة، يبقى `api/v1/courses.json` كتالوجاً صالحاً وفارغاً.
