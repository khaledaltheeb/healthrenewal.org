# Authorized course feeds

هذا المجلد مخصص حصراً لملفات JSON التي يثبت الإذن بإعادة استخدام بياناتها الوصفية.

## شروط القبول

- هوية مقدم الخدمة ورابط موقعه الرسمي عبر HTTPS.
- دليل إذن عام وغير حساس عبر HTTPS، ونطاق ترخيص واضح، وتاريخ تحقق غير مستقبلي.
- عدم انتهاء صلاحية الإذن.
- رابط قانوني أصلي لكل دورة ورابط تسجيل رسمي.
- `rights.metadataReuse` يساوي `true`.
- نص إسناد واضح في `rights.attributionText`.
- تواريخ `date-time` تتضمن منطقة زمنية صريحة.
- السعر رقم محدود وغير سالب، مع رمز عملة ISO 4217 مثل `JOD` عند وجود سعر.
- عدم تضمين فيديوهات أو ملفات أو اختبارات أو مفاتيح تصحيح أو مواد تدريبية محمية.

## الخصوصية

المستودع عام. لذلك يُمنع وضع مراسلات خاصة، أو روابط موقعة مؤقتة، أو بيانات شخصية، أو مستندات إذن سرية داخل ملفات التغذية.

الحقل `authorization.evidenceUrl` مخصص لرابط تحقق عام غير حساس. يتحقق منه الناشر، لكنه لا يظهر في `api/v1/courses.json`. الكتالوج العام يعرض فقط أن الدليل تحقق، ونوع الترخيص، وتاريخ التحقق، وتاريخ انتهاء الإذن إن وجد.

يُفضّل ملف واحد لكل مقدم خدمة. إذا احتاج مقدم واحد إلى عدة مجموعات دورات، تُجمع في مصفوفة `courses` داخل الملف نفسه لتجنب تعارض الهوية.

## الصيغة

استخدم العقد المنشور في:

```text
api/v1/courses.schema.json
```

ويمكن مراجعة المثال البنيوي في:

```text
api/v1/courses.example.json
```

كل ملف منتهي بـ `.json` داخل هذا المجلد يُعامل كتغذية إنتاجية، لذلك لا تُحفظ أمثلة أو مسودات هنا. عند غياب أي تغذية مخولة، يبقى `api/v1/courses.json` كتالوجاً صالحاً وفارغاً.
