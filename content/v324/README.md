# مسارات التوحد السريرية المتقدمة — v324

تنشر الحزمة أربع صفحات عربية موسعة غير مكررة مع المسارات السابقة:

1. التقييم الشامل والتشخيص التفريقي.
2. التشخيص المتأخر لدى البالغين والنساء والتمويه.
3. تقييم التواصل المعزز والبديل وتنفيذه.
4. العلاجات غير المثبتة أو الخطرة وكيفية تقييم الادعاءات.

## تخزين المصدر والتحقق منه

يُخزن المصدر المضغوط بصورة خمسة ملفات Base64 نصية داخل:

`autism-clinical-pathways-ar.parts/part-01.b64` إلى `part-05.b64`.

يجمع الناشر الأجزاء بالترتيب ويزيل محارف الفراغ فقط، ثم يفرض العقود التالية قبل قراءة المحتوى:

- عدد الأجزاء وأسماؤها ثابتان.
- طول Base64 المجمع: `24652` حرفًا.
- SHA-256 لنص Base64: `3a1b4b14d25d67b6f72a50d42d45cabc26382f5841fbd4a7e2d7c11e4a44f2eb`.
- فك Base64 يستخدم التحقق الصارم `validate=True`.
- SHA-256 لبايتات Gzip: `3350205c4f20177d4cb10fc80c5c9058abffc50c3092f1a60efbc9e96913db5b`.
- SHA-256 لبايتات JSON بعد فك Gzip: `0afeb714ceb04a83b0c2debce97004f87aa104328a7d0070d892b437adc66c17`.
- يجب نجاح UTF-8 وJSON وأن تكون النتيجة كائنًا منظمًا.

يفشل البناء عند اختلاف حرف أو جزء أو بصمة؛ فلا يعتمد النشر على ملف ثنائي قد يتغير أثناء النقل عبر واجهات المستودع النصية.

## عقد المحتوى

- أربعة مسارات ثابتة و28 محورًا تحليليًا.
- فقرتان تحليليتان وأربعة أسئلة تحقق في كل محور.
- ست خطوات عملية وثلاث علامات استعجال في كل صفحة.
- 26 مرجعًا معلنًا، ويجب استخدام كل مرجع داخل محور ظاهر.
- حد أدنى 1250 كلمة ظاهرة لكل صفحة.
- H1 واحد وسبعة أقسام موثقة وبيانات منظمة وخريطة موقع.
- غلاف مؤسسي موحد وحقوق ملكية وأصول الواجهة.
- ربط واحد من مركز التوحد وثبات كامل عند إعادة النشر.

## حدود علمية ملزمة

- لا تُحوّل أداة التحري أو المقابلة أو درجة الاختبار إلى تشخيص منفرد.
- التمويه مفهوم بحثي متطور وليس اختبارًا تشخيصيًا مستقلًا.
- التواصل المعزز والبديل ليس حلًا أخيرًا بعد فشل الكلام ولا يُسحب لإجبار الشخص على الكلام.
- الشهادة الشخصية لا تثبت فعالية علاج ولا تنفي ضرره.
- الاستخلاب والسيكريتين والأكسجين عالي الضغط ليست علاجات معتمدة للسمات الأساسية للتوحد، وقد تحمل مخاطر.
- المحتوى لا يصف مراجعة سريرية خارجية مكتملة؛ الحالة هي `internally-reviewed-external-clinical-review-required`.
