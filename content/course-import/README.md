# تشغيل تكامل الدورات المخولة

هذا المجلد مخصص **لبيانات الدورات الوصفية فقط**. لا تُحفظ هنا فيديوهات أو ملفات تدريب أو اختبارات أو نصوص دروس خارجية.

## إضافة مزود

1. احصل على إذن مكتوب يحدد ما يسمح بإعادة استخدامه، وتأكد أن البيانات الوصفية مسموحة وأن نسخ المحتوى غير مسموح إلا إذا نص الترخيص صراحة على خلاف ذلك.
2. أضف المزود إلى `registry.json` وفق `api/v1/course-provider-registry.schema.json`.
3. اجعل الحالة `authorized` فقط بعد التحقق من هوية الجهة، رابط دليل الإذن، الترخيص، تاريخ التحقق، وتاريخ الانتهاء إن وجد.
4. حدد نطاقات HTTPS المسموح بها في `allowedHosts` وحدًا أقصى لحجم feed. يفضّل تثبيت `sha256` عندما يوفر المزود ملفًا ثابتًا أو إصدارًا موقعًا.
5. للاختبار والنشر الاعتيادي، ضع نسخة feed المصرح بها في `content/course-import/feeds/<provider-id>.json`.

## الاتصال الشبكي

الاتصال الشبكي معطل افتراضيًا حتى عند وجود مزود حالته `authorized`. للتشغيل المقصود يلزم معًا:

```text
COURSE_IMPORT_NETWORK_ENABLED=1
COURSE_IMPORT_APPROVED_PROVIDERS=provider-one,provider-two
```

ثم يُشغّل المستورد مع `--fetch-remote`. لا تستخدم هذه الآلية لتجاوز تسجيل الدخول أو الجدران المدفوعة أو القيود التقنية.

## التعليق والإلغاء

- `suspended`: إيقاف مؤقت أثناء مراجعة الإذن أو جودة البيانات.
- `revoked`: أُلغي الإذن أو لم يعد يسمح بالنشر.
- `expired`: انتهت مدة التفويض.

لا تُحذف الأدلة التاريخية على الإذن عند تغيير الحالة؛ تُحفظ وفق سياسة الخصوصية والاحتفاظ المؤسسية، بينما يستبعد المستورد أي مزود غير `authorized` من الكتالوج المنشور.

## المخرجات

- `/api/v1/courses.json`: كتالوج القراءة العامة.
- `/courses/`: واجهة بشرية تربط إلى الصفحات الأصلية والتسجيل لدى المزود.
- `/sitemap-courses.xml`: خريطة صفحة الكتالوج.
- `/api/course-import-v218.json`: تقرير البناء، دون أسرار أو بيانات شخصية.

الإدراج لا يعني اعتماد المنصة لجودة الدورة، ولا يحول المنصة إلى جهة تسجيل أو دفع أو إصدار شهادات.
