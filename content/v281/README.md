# توسعة أدلة الحالات v281

تضيف هذه الدفعة **50 حالة جديدة** إلى مكتبة v280 المكونة من 100 حالة. الأرقام 101–150 تنظيمية وليست ترتيبًا للشدة أو القيمة أو الانتشار.

## الحقيقة المصدرية

لا تُحفظ البيانات العلمية في ملف مضغوط داخل Git. تتكون الحقيقة القابلة للمراجعة من:

- `metadata-ar.json`: حدود المحتوى، حالة المراجعة، المصادر العامة، وقواعد كل فئة.
- `conditions/chromatin-syndromic.jsonl`: 21 متلازمة جينية ونمائية عصبية.
- `conditions/developmental-epileptic.jsonl`: 15 اعتلالًا نمائيًا وصرعيًا.
- `conditions/metabolic-neurodegenerative.jsonl`: 14 مرضًا استقلابيًا أو تقدميًا.

ينشئ `scripts/build_conditions_v281_data.py` حمولة مضغوطة حتمية مؤقتة يحتاجها الناشر القديم، ثم ينشئ `scripts/publish_conditions_v281.py` الصفحات وتقرير API ونسخة JSON واضحة داخل Artifact النشر.

## الصفحات

- فهرس الدفعة: `/capabilities/expanded/`
- 50 صفحة فردية: `/capabilities/<slug>/`
- تقرير النشر: `/api/capabilities-v281.json`
- نسخة المصدر المادية: `/api/capabilities-v281-source.json`
- خريطة الدفعة: `/sitemap-capabilities-v281.xml`

بعد نجاح v280، تحتوي Artifact النهائية على **155 صفحة** داخل `/capabilities/`: أربع صفحات بنيوية و100 صفحة v280 وصفحة فهرس v281 و50 صفحة جديدة.

## بنية كل سجل

كل حالة تتضمن:

1. الاسم العربي والإنجليزي والمسار الدائم.
2. السبب أو الآلية المعروفة مع حدود التنبؤ.
3. النمط السريري والتباين الفردي.
4. أولويات المتابعة الصحية.
5. مسار التشخيص والتقييم.
6. الرعاية أو التدخل المقبول دون جرعات أو وصفة فردية.
7. علامات الخطر.
8. قدرة أو فرصة وظيفية قابلة للاختبار.
9. مدخلًا مستقلًا في NCBI Bookshelf للوصول إلى المراجع المتخصصة.

يضيف الناشر إلى ذلك خطط الأسرة ومقدم الخدمة والتواصل والوصول والتجارب الصغيرة والممارسات الواجب تجنبها.

## ضوابط المحتوى

- المحتوى تثقيفي ولا يشخّص شخصًا ولا يغير دواء أو جرعة أو حمية.
- لا توجد مصادقة أو مراجعة سريرية خارجية مستقلة حتى الآن.
- لا تُقدَّم النوبات أو الألم أو التدهور أو الحرمان من النوم بوصفها نقاط قوة.
- اسم التشخيص لا يحدد الذكاء أو المهنة أو حق القرار.
- القدرة فرضية فردية تُختبر بعد تثبيت الصحة والأمان والوصول.
- يُمنع استخدام مصطلح «معاقين» في البيانات أو الصفحات.

## اختبارات المنع

تمنع `tests/test_conditions_v281.py` النشر عند:

- نقص أو زيادة عدد الحالات عن 50 أو الرتب عن 101–150.
- تكرار مسار من v280 أو داخل v281.
- تكرار مصدر أو حقل حالة كامل.
- تشابه مرتفع بين الحزم الخاصة بالحالات.
- نقص عمق الحقول أو مصدر رسمي.
- صفحة أقل من 1000 كلمة أو بلا canonical أو Schema أو حدود مراجعة.
- اختلاف نتيجة البناء بين تشغيلين.
- غياب سلسلتي النشر والتحقق الحي.
