# سجل التغيير v234

## المحتوى

- توسيع مكتبة النصائح من 20 إلى 36 دليلًا عمليًا.
- إضافة موضوعات: نوبات الهلع، التفكير الزائد، الإسعاف النفسي الأولي، التعافي بعد الأزمات، رفض المدرسة، خلافات الإخوة، السلامة الرقمية، التنمر، التهيئة الحسية، الانتقالات، احتراق مقدم الرعاية، حدود العمل، التركيز، الوحدة، حزن الطفل، والاستعداد للجلسة الأولى.
- إعادة بناء الأدلة السابقة ضمن قالب أعمق يضم الأهداف والخطوات والجملة الجاهزة والمحاذير ومؤشرات التحسن وحدود طلب المساعدة والأسئلة الشائعة والمصادر.

## البنية

- 9 صفحات فئات.
- 3 صفحات مؤسسية: طريقة الاستخدام، المنهجية، والمساعدة العاجلة.
- 49 صفحة إجمالية داخل القسم.
- API وSitemap وتقرير تدقيق مستقل.

## الجودة

- بيانات وصفية وفهرسة كاملة لكل صفحة.
- بيانات منظمة متعددة الأنواع.
- دعم RTL ولوحة المفاتيح والطباعة وتقليل الحركة.
- اختبارات للتكرار والروابط واللغة والسلامة والبيانات المنظمة والبناء المتكرر.
