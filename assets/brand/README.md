# هوية منصة روافد

الاسم الرسمي: **منصة روافد**  
العبارة المؤسسية: **للعافية النفسية والدمج والتمكين**

تُستخدم الأصول المتجهة والنقطية الموجودة في هذا المجلد في الهيدر، الفوتر، بيانات المشاركة الاجتماعية، وأيقونات التطبيقات والمتصفح. الألوان الأساسية للهوية: التركواز، الفيروزي، الأخضر الحيوي، والذهبي الدافئ.
