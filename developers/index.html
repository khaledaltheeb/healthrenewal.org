بوابة المطورين والبيانات المفتوحة المنضبطة

توفر البوابة نقطة بداية للمطورين والباحثين والمؤسسات الراغبة في اكتشاف بيانات المنصة أو التكامل معها ضمن الحقوق المعلنة. يجب احترام الترخيص والإسناد وحدود المحتوى الصحي وعدم استخدام البيانات لبناء تشخيص آلي أو ادعاءات تتجاوز المصدر.

فتح واجهة APIاختيار المسار المناسب
حدود مهنية: هذه الصفحة للتثقيف والتنظيم العام. لا تثبت تشخيصًا، ولا تختار علاجًا أو دواءً، ولا تستبدل التقييم الفردي أو خدمات الطوارئ المحلية عند الخطر المباشر.

ما الذي تجده في هذه البوابة؟

صُممت الصفحة لتكون مدخلًا عمليًا ومؤسسيًا، وتربط كل تكامل بالعقد والإصدار والحقوق وحدود الاستخدام بدل الاعتماد على استخراج عشوائي للمحتوى.

اكتشاف

العقود والملفات

ابدأ بواجهة API العامة وملف OpenAPI والملفات القابلة للقراءة آليًا لمعرفة المسارات والحقول والإصدارات.

نسخ وإصدار

توافق واستقرار

اعتمد رقم الإصدار والحقول الموثقة، ولا تفترض ثبات بنية غير معلنة أو تستخرج المحتوى من HTML عند توفر عقد بيانات.

حقوق

إسناد وترخيص

راجع حقوق النشر ونطاق الاقتباس وإعادة الاستخدام، واحتفظ بالمصدر والرابط وتاريخ الاسترجاع.

سلامة

استخدام مسؤول

لا تحول المحتوى التثقيفي إلى قرار سريري آلي، ولا تجمع بيانات حساسة أو تعيد تحديد الأشخاص.

طريقة التكامل

ابدأ بحالة استخدام محددة، ثم ابنِ التكامل على عقد معلن مع تحقق دفاعي وإسناد واضح.

حدد حالة الاستخدام

اكتب الغرض والجمهور والحقول المطلوبة والمخاطر قبل بدء التكامل.

راجع العقد

تحقق من OpenAPI والمخططات وأنواع البيانات والقيم المطلوبة ورسائل الخطأ.

ابنِ تحققًا دفاعيًا

تعامل مع الحقول المفقودة والإصدارات الجديدة ومحددات المعدل وفشل الشبكة دون كسر التطبيق.

وثق المصدر

اعرض الإسناد والتاريخ والإصدار وحدود المحتوى للمستخدم النهائي.

موارد المطور

ابدأ بالعقود الرسمية، ثم راجع الحقوق والحوكمة وسجل المصادر قبل إعادة الاستخدام.

أسئلة شائعة

هل يمكن نسخ كل محتوى المنصة؟

لا يُفترض ذلك. راجع حقوق النشر والترخيص لكل مورد، واستخدم الواجهات المعلنة بدل النسخ الآلي غير المنضبط.

هل API بديل عن مراجعة المصدر؟

لا. البيانات تسهل الاكتشاف والتكامل، لكن الادعاءات العلمية تحتاج إلى المصدر الأصلي وسياقه وحدوده.

هل يمكن استخدام البيانات لتشخيص المستخدمين؟

لا. المحتوى تثقيفي، وبناء تشخيص آلي أو قرار علاجي يتطلب إطارًا سريريًا وقانونيًا وأخلاقيًا مختلفًا.
