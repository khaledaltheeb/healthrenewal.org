قائمة فحص اختيار التقنية المساعدة

استخدمها قبل الشراء وأثناء التجربة وبعد التسليم. لا تمنح درجة تشخيصية ولا تستبدل تقييمًا مهنيًا. وجود علامة أمام بند يعني أنه نوقش ووُثق، لا أنه تحقق تلقائيًا.

أولًا: تعريف الحاجة

1. الهدف وظيفي ومحدد.
وُصف النشاط المطلوب بدل الاكتفاء باسم الحالة أو المنتج.
2. أولوية الشخص واضحة.
سُئل الشخص عن ما يهمه وطريقة الدعم التي يقبلها.
3. خط الأساس موثق.
نعرف ما يحدث الآن، وكم يستغرق، وما مقدار المساعدة أو الخطر.
4. الحواجز البيئية محددة.
المكان والضوضاء والإضاءة والاتصال والمبنى والسياسات والدعم البشري.
5. البدائل غير التقنية نوقشت.
تعديل الروتين أو البيئة أو التعليمات أو الدعم قد يكون كافيًا أو مكملًا.

ثانيًا: التقييم والوصول

6. التقييم مباشر ومتعدد السياقات.
لم يعتمد القرار على وصف أو اختبار منفرد.
7. طريقة الإدخال مناسبة.
لمس، لوحة مفاتيح، مفتاح، نظر، صوت، مسح، حركة رأس أو غيرها.
8. طريقة الإخراج قابلة للوصول.
صوت، نص، رموز، اهتزاز، حجم وتباين وسرعة مناسبة.
9. الألم والوضعية والإجهاد روجعت.
خصوصًا في الجلوس والحركة والوصول المتكرر.
10. التواصل والرفض محفوظان.
يمكن للشخص الرفض وطلب التوقف والمساعدة والإبلاغ عن الألم.

ثالثًا: البدائل والتجربة

11. قورنت بدائل متعددة.
شملت حلًا منخفض التقنية وحلًا آخر إن أمكن.
12. جرت تجربة حقيقية.
في المنزل أو المدرسة أو العمل أو النقل، لا في العرض فقط.
13. كانت المدة كافية.
سمحت بالتعلم وظهور الأعطال والصعوبات الواقعية.
14. رأي الشخص موثق.
الراحة والقبول والكرامة والوصم والاختيار.
15. نتائج التجربة قابلة للمقارنة.
وقت، دقة، مشاركة، استقلال، تعب، أخطاء أو مخاطر.

رابعًا: الأمان والخصوصية

16. تعليمات المصنع والتحذيرات متاحة.
بلغة وطريقة يفهمها المستخدم والداعمون.
17. التوافق والنقل والتثبيت تحققت.
خصوصًا الكراسي والمقاعد والمركبات والشواحن والملحقات.
18. خطة الطوارئ والتعطل مكتوبة.
بديل تواصل أو حركة أو وصول عند توقف التقنية.
19. البيانات مفهومة.
ما يُجمع، أين يُخزن، من يراه، وكيف يُحذف أو يُنسخ احتياطيًا.
20. التنبيهات الحمراء معروفة.
ألم، تغير جلد، صعوبة تنفس أو بلع، سقوط، حرارة، خلل بطارية أو تغير مفاجئ.

خامسًا: الشراء والتمويل

21. التكلفة الكلية محسوبة.
الجهاز والملحقات والاشتراك والتدريب والصيانة والقطع والنقل.
22. التمويل لا يلغي الاختيار.
عُرضت الخيارات حتى لو اختلفت تغطيتها أو سعرها.
23. الضمان والإرجاع واضحان.
المدة والاستثناءات ومكان الخدمة ومن يتحمل الشحن.
24. المورد والدعم قابلان للتحقق.
عنوان رسمي وقطع غيار وخدمة محلية أو إقليمية.
25. تضارب المصالح معلن.
أي عمولة أو علاقة بين المقيّم والمورد أو المصنع.

سادسًا: التسليم والتدريب والمتابعة

26. تم الضبط والملاءمة عند التسليم.
إعدادات، مقاس، وضعية، حسابات، وصول وملحقات.
27. تدرب الشخص والشركاء.
الاستخدام اليومي والتنظيف والشحن وحل المشكلات الأساسية.
28. التوثيق متاح.
سبب الاختيار والإعدادات والرقم التسلسلي والضمان وخطة المتابعة.
29. موعد المراجعة محدد.
بعد التسليم ثم دوريًا أو عند تغير الصحة أو البيئة أو الهدف.
30. معايير التعديل أو الإيقاف واضحة.
الضرر أو عدم الاستخدام أو تغير الحاجة أو ظهور بديل أنسب.
