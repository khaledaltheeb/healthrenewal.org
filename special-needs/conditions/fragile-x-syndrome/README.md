# دليل متلازمة الكروموسوم X الهش

الحزمة المنشورة تتكون من:

1. البوابة الرئيسية والخلاصة التنفيذية.
2. الجينات والتشخيص والاستشارة الوراثية.
3. الصحة والمتابعة عبر مراحل الحياة.
4. التواصل والتعليم والوصول إلى التعلم.
5. السلوك والقلق والتدخل الآمن.
6. الأسرة والسلامة والحقوق والانتقال للرشد.

يربط `evidence.json` الادعاءات بالمصادر، وتغطي `sitemap-fragile-x-syndrome.xml` جميع صفحات HTML العامة. يفرض اختبار النشر حدًا أدنى لطول الصفحات والمحتوى الكلي، ويفحص canonical وRTL وSchema والمصادر والروابط.
