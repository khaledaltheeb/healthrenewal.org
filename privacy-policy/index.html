شفافية تشغيلية — لا وعود فضفاضة

سياسة الخصوصية واستخدام البيانات

تشرح هذه الصفحة ما قد يحدث للبيانات عند تصفح منصة روافد أو استخدام أدواتها ونماذجها وحساباتها. المنصة تتناول موضوعات صحية ونفسية واجتماعية حساسة؛ لذلك نوصي بعدم إدخال أسماء كاملة أو تشخيصات أو تقارير أو أرقام هوية أو تفاصيل يمكن أن تكشف شخصًا ما لم تكن الخدمة تطلبها بوضوح وكانت هناك حاجة فعلية وآلية آمنة.

قاعدة أمان أساسية: صفحات التثقيف والاختبارات والأدوات العامة ليست قناة علاج سرية ولا سجلًا طبيًا. لا تستخدمها لإرسال حالة طارئة أو معلومات شديدة الحساسية. عند الخطر المباشر استخدم خدمة طوارئ محلية رسمية.

1. نطاق هذه السياسة

تشمل السياسة صفحات الموقع العامة، الأدوات التي تعمل داخل المتصفح، النماذج، ومناطق الحسابات أو البوابات المتخصصة التابعة لنطاق المنصة. لا تحكم المواقع الخارجية التي تصل إليها عبر رابط؛ لكل جهة سياسة مستقلة يجب قراءتها قبل إدخال البيانات.

2. فئات البيانات التي قد تُعالج

بيانات تقنية وتشغيلية

قد تتضمن عنوان الشبكة، نوع المتصفح والجهاز، الصفحات المطلوبة، وقت الزيارة، الأخطاء، والمُحيل. قد تنتج هذه البيانات من الاستضافة وشبكات التوزيع والحماية حتى دون إنشاء حساب.

بيانات تحليل الاستخدام

تستخدم بعض صفحات المنصة قياسًا تحليليًا لفهم الزيارات والأداء ومسارات الوصول. قد تستخدم أدوات التحليل ملفات تعريف أو معرّفات تقنية وفق إعداداتها وسياسة مزودها.

بيانات محفوظة محليًا

بعض الأدوات تحفظ مدخلات أو تفضيلات أو تقدمًا داخل localStorage أو sessionStorage في جهاز المستخدم. هذا لا يعني أنها أُرسلت تلقائيًا إلى خادم المنصة، لكنه يعني أن من يصل إلى الجهاز أو ملف المتصفح قد يراها.

بيانات يرسلها المستخدم

قد تشمل رسالة تواصل، بيانات حساب، طلب استعادة، ملف مختص، إجابة نموذج، أو بيانات خدمة. تختلف الحقول والغرض بحسب الصفحة؛ لا تجمع المنصة بيانات حساسة لمجرد أنها قد تكون مفيدة مستقبلًا.

3. لماذا تُستخدم البيانات؟

  • تشغيل الصفحة أو الأداة وإتاحة الوظيفة التي طلبها المستخدم.
  • حماية الحسابات واكتشاف الأعطال أو إساءة الاستخدام والطلبات الآلية الضارة.
  • تحسين السرعة والإتاحة وبنية التنقل وجودة المحتوى استنادًا إلى مؤشرات مجمعة.
  • الرد على رسالة أو إدارة طلب صريح، مثل التسجيل أو استعادة الحساب أو تحديث ملف.
  • الامتثال لالتزام قانوني واجب أو حماية الحقوق والسلامة عند وجود أساس مشروع واضح.

لا تُستخدم البيانات الصحية أو النفسية لبناء تشخيص آلي نهائي، ولا يجوز تفسير نتيجة اختبار تثقيفي بوصفها قرارًا علاجيًا.

4. خريطة التخزين والمشاركة

المسارمكان المعالجة المحتملما الذي يجب أن يعرفه المستخدم؟
تصفح صفحة عامةالاستضافة وشبكة التوزيع وقياس الاستخدامقد تُسجل طلبات تقنية وسجلات أمنية وتحليلية وفق إعدادات الخدمات المستخدمة.
أداة محليةجهاز المستخدم أساسًامسح بيانات الموقع من المتصفح قد يحذف السجل المحلي؛ لا تستخدم جهازًا مشتركًا لمعلومات حساسة.
نموذج أو حسابخدمة خلفية أو بريد أو قاعدة بيانات مخصصةاقرأ التنبيه داخل النموذج، ولا ترسل أكثر مما يلزم لتنفيذ الطلب.
رابط أو محتوى خارجيموقع الجهة الخارجيةقد تتلقى الجهة عنوان الشبكة ومعرّفات المتصفح وتطبق سياسة مستقلة.

5. البيانات الحساسة والأطفال

المعلومات الصحية والنفسية والتعليمية وبيانات الأطفال تحتاج تقليلًا وحماية أعلى. يجب على ولي الأمر أو الجهة المهنية تجنب رفع تقرير كامل عندما تكفي خلاصة غير معرفة، وإزالة الاسم والرقم الوطني والعنوان والصور وأسماء المدارس أو المرافقين من أي ملف غير ضروري. لا ينبغي للطفل إرسال معلومات تعريفية أو صور أو تفاصيل علاجية دون إشراف بالغ مسؤول.

6. الاحتفاظ والحذف

تختلف مدة الاحتفاظ بحسب المسار: بيانات المتصفح المحلية تبقى حتى حذفها أو انتهاء الجلسة؛ السجلات التقنية قد يحتفظ بها مزود الاستضافة أو الحماية وفق سياسته؛ بيانات الحساب أو الطلب تبقى بقدر الحاجة التشغيلية والأمنية والقانونية. عند طلب حذف بيانات يمكن ربطها بالمستخدم، يجب تحديد الخدمة والحساب أو الرسالة المتأثرة دون إرسال بيانات إضافية غير لازمة.

7. خيارات المستخدم وإجراءاته

  • استخدم إعدادات المتصفح لحظر أو حذف ملفات التعريف والتخزين المحلي، مع العلم أن بعض الأدوات قد تفقد التقدم أو الإعدادات.
  • استخدم نافذة خاصة أو جهازًا شخصيًا عند التعامل مع موضوع حساس، وسجل الخروج من أي بوابة حساب.
  • لا تشارك كلمة مرور أو رمز استعادة أو مفتاح وصول عبر نموذج عام.
  • اطلب الوصول أو التصحيح أو الحذف أو تقييد المعالجة عبر صفحة التواصل مع تحديد الخدمة دون إرفاق سجل صحي كامل.
  • أبلغ عن ثغرة أو كشف غير مقصود فورًا، ولا تنشر البيانات أو تستغلها.

8. الأمان وحدوده

تُستخدم ضوابط تقنية وتنظيمية مناسبة لطبيعة الخدمة، لكن لا توجد وسيلة نقل أو تخزين مضمونة بالكامل. مسؤولية المنصة هي تقليل البيانات، تقييد الوصول، تحديث المكونات، واختبار المسارات؛ ومسؤولية المستخدم تشمل حماية الجهاز وكلمة المرور وعدم إدخال معلومات غير لازمة.

لا ضمان للسرية العلاجية: استخدام المنصة لا ينشئ علاقة علاجية أو امتيازًا مهنيًا مشابهًا لسجل عيادة، إلا إذا نصت خدمة محددة وعقد مستقل بوضوح على غير ذلك.

9. التغييرات والمراجعة

تُراجع هذه السياسة عندما تتغير أدوات التحليل أو الحسابات أو النماذج أو مزودات الاستضافة أو المتطلبات النظامية. يُعرض تاريخ المراجعة أدناه، ويجب أن توضح أي خدمة جديدة عالية الحساسية إشعارها الخاص قبل جمع البيانات.

أسئلة شائعة

هل تحفظ كل الأدوات إجاباتي على الخادم؟

لا. توجد أدوات تعمل محليًا داخل المتصفح، وأخرى قد تتصل بخدمة خلفية. وجود زر حفظ أو حساب أو إرسال يعني ضرورة قراءة التنبيه الخاص بالصفحة؛ أما التخزين المحلي فيمكن فحصه وحذفه من إعدادات بيانات الموقع.

هل يمكن إرسال تقرير طبي عبر نموذج عام؟

الأصل هو عدم إرساله. ابدأ بوصف مختصر غير معرف، واطلب قناة آمنة وتعليمات واضحة عند وجود حاجة مهنية حقيقية للملف.

هل الروابط الخارجية جزء من المنصة؟

لا. نراجع الروابط لأغراض الجودة، لكن الموقع الخارجي يحدد جمعه واستخدامه للبيانات، وقد يغير ممارساته دون سيطرة المنصة.
